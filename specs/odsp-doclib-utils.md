# @fluidframework/odsp-doclib-utils (3.11.0)

## Role

ODSP host/authority helpers, OAuth URL construction and one-refresh request adapter, claims/tenant challenge parsing, and HTTP error mapping shared by the ODSP driver. It does not perform an interactive OAuth sign-in or persist tokens. Sources: `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspAuth.ts:11-113`, `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspDocLibUtils.ts:6-109`, `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspErrorUtils.ts:206-478`.

## Wire and persisted formats

Tokens `{accessToken:string,refreshToken?:string,receivedAt?:number,expiresIn?:number}`; receivedAt/expiresIn **seconds**. Public config `{clientId:string}`. Request credentials union `{grant_type:"authorization_code",code:string,redirect_uri:string}` / `{grant_type:"refresh_token",refresh_token:string}` / `{grant_type:"password",username:string,password:string}`. Type only: no token POST encoder exists here. auth adapter info `{accessToken:string,refreshTokenFn?:()->Promise<string>}`. Sources: `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspAuth.ts:11-51`.

Storage scope literal `offline_access <getSiteUrl(server)>/AllSites.Write`; pushScope=`offline_access https://pushchannel.1drv.ms/PushChannel.ReadWrite.All`. Token URL `<aadUrl>/<aadTenant>/oauth2/v2.0/token`. Login URL concatenates raw `?client_id=<id>&scope=<scope>&response_type=code&redirect_uri=<redirect>`; it does **not** call URLSearchParams/encodeURIComponent. Example server t-my.sharepoint.com,client=c,redirect=https://app/cb gives `https://login.microsoftonline.com/t.onmicrosoft.com/oauth2/v2.0/authorize?client_id=c&scope=offline_access https://t-my.sharepoint.com/AllSites.Write&response_type=code&redirect_uri=https://app/cb`. Sources: `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspAuth.ts:57-89`, `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspDocLibUtils.ts:38-82`.

Challenge `WWW-Authenticate: Bearer realm="t", error="insufficient_claims", claims="eyJhIjoxfQ=="` produces tenant t and unencoded JSON claims `{"a":1}`. Service errors are JSON `{error:{message:string,code?:string,innerError?:{code?:string,innerError?:...},"@error.redirectLocation"?:string}}`; parsed facet array is deepest code first. Detailed complete status mapping and retry consumers are in [ODSP auth/error contract](odsp-driver/auth-errors.md); the map is also enumerated below. Sources: `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/parseAuthErrorClaims.ts:20-46`, `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/parseAuthErrorTenant.ts:24-53`, `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspErrorUtils.ts:120-199`.

## Behavior

isOdspHostname strips /^https?:\/\//i, takes first component split by slash/colon, lowercases; accepts bare sharepoint.com/sharepoint-df.com or dot-suffixed subdomains, rejects lookalikes. isPushChannelHostname is case-sensitive `includes(".push") && endsWith(".svc.ms")`, with no normalization. getAadUrl localhost or localhost:prefix→http://server, push channel→getSiteUrl(server), otherwise https://login.microsoftonline.com. getSiteUrl returns unchanged if starts lowercase http:// or https://, else prepends https://. getServer map spo→microsoft-my.sharepoint.com, spo-df→microsoft-my.sharepoint-df.com, otherwise Error. Sources: `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspDocLibUtils.ts:6-109`.

getAadTenant strips lowercase http/https, splits first hostname label via indexOf("."), lowercases tenant/rest, strips tenant suffix -my or -admin, replaces initial .sharepoint.→.onmicrosoft. or .sharepoint-df.→.onmicrosoft., returns tenant+rest. It does not parse a URL or discard path/port, so supplying a whole path can appear in returned tenant. authRequestWithRetry issues callback with `{headers:{Authorization:"Bearer "+accessToken}}`; only if refreshTokenFn exists and response status401/403, await refresh and issue callback once more. Does not mutate authRequestInfo/accessToken, parse claims, or catch a callback rejection. Sources: `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspDocLibUtils.ts:57-82`, `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspAuth.ts:92-113`.

Claims parser splits commas and equals; case-fold keys; error RHS JSON.parse after lowercase; claims RHS takes substring after first equal so base64 padding preserved; decode UTF8, return only insufficient_claims. Tenant parser requires case-sensitive Bearer anywhere, scans following comma sections, first truthy realm parsed using first equals RHS. Neither catches malformed header JSON. Sources: `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/parseAuthErrorClaims.ts:20-46`, `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/parseAuthErrorTenant.ts:24-53`.

Error recognition catches JSON.parse errors and returns success:false; valid error needs error.message string and code absent/string. parseFacetCodes walks object/non-null innerError and unshifts every defined code. Status mapping: redirects301/302/303/307/308+Location→OdspRedirectError; without Location fall through400; 400 fluidInvalidSchema→FluidInvalidSchemaError, fluidEpochNotProvided→retryable usageError, else nonretryable genericNetworkError; 401/403 deepest serviceReadOnly→retryable serviceReadOnly, blockedIPAddress/conditionalAccessPolicyEnforced→nonretryable blockedIPAddress, else AuthorizationError(claims,tenant); 404 defined body redirect→OdspRedirectError else nonretryable fileNotFoundOrAccessDeniedError; 406 unsupportedClientProtocolVersion,410 cannotCatchUp,409 fileOverwrittenInStorage,412 genericNetworkError,413 snapshotTooBig,414 invalidFileNameError,501 fluidNotEnabled,507 outOfStorageError,712 incorrectServerResponse all nonretryable. 423 resourceLocked/resourceCheckedOut→nonretryable fileIsLocked else fallthrough500 retryable genericNetworkError. All remaining statuses use createGenericNetworkError(canRetry:true,retryAfterMs:seconds*1000 if defined), including429. Sources: `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspErrorUtils.ts:158-412`.

createOdspNetworkError adds endpointReached, enriches online enum name, facets, responseType, serverEpoch and headers. throwOdspNetworkError parses retry-after as Number (missing/NaN→undefined), adds odspError/storageServiceError and throws. hasFacetCodes only checks Array.isArray(x?.facetCodes), not elements; hasRedirectionLocation requires nonnull object, property in object and string. Sources: `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspErrorUtils.ts:409-500`.

Telemetry headers map sprequestguid→same, request-id→requestId, client-request-id→clientRequestId, x-msedge-ref→xMsedgeRef, X-Fluid-Retries→serverRetries, content-encoding→contentEncoding, content-type→contentType. sprequestduration/content-length parsed numerically. x-fluid-telemetry retained raw and comma/equals parsed; first trimmed key Origin maps c→cache,g→graph,otherwise trimmed value. Sources: `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspErrorUtils.ts:50-112`.

## Invariants and asserts

None in these utility algorithms. OdspRedirectError always errorType=fileNotFoundOrAccessDeniedError,canRetry=false and excludes redirectLocation from telemetry. Network status/retryability may be overridden by driver's epoch/socket wrappers; utility does not enforce epoch equality. Sources: `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspErrorUtils.ts:141-152`, `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspErrorUtils.ts:206-412`.

## JS-semantics hazards

Do not add OAuth percent-encoding to URL builder outputs when comparing with oracle strings. Claim header grammar is literal comma splitting, not a complete RFC parser. retry-after is numeric seconds only (date→undefined). Tenant helper's string slicing is not URL.hostname parsing. Auth adapter does not store refreshed accessToken for future requests. Sources: `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspAuth.ts:77-113`, `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/parseAuthErrorClaims.ts:28-46`, `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspDocLibUtils.ts:57-82`, `reference/fluidframework-3.11.0/packages/utils/odsp-doclib-utils/src/odspErrorUtils.ts:470-478`.
