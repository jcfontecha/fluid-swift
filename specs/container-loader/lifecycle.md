# Container-loader: load, attach and close

## 1. Role

Container coordinates service creation, protocol and runtime construction, saved-op replay, eligibility events, attachment and terminal cleanup. Lifecycle state starts loading and progresses through loaded/closing/disposing/closed/disposed; attach state and connection state are independent state machines. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:456-477`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/attachment.ts:23-83`.)

## 2. Surface used by other packages

Static load, createDetached, rehydrateDetachedFromSnapshot underpin host helpers. Runtime receives context with submission, dirty/pending-op and close callbacks; host observes attaching/attached, connected/disconnected, readonly, op, closed/disposed. `serialize` is for detached/attaching; `getPendingLocalState` is for attached open containers. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:331-390`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1187-1247`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1279-1293`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:2457-2492`.)

## 3. Wire and persisted formats

Attachment sends a **summary** to createContainer, not a document-level `attach` op. No-blobs attachment provides combined `.protocol`/`.app` summary at document creation. With blobs it first creates document with undefined summary, uploads blobs, then uploadSummaryWithContext(summary,{referenceSequenceNumber:0,ackHandle:undefined,proposalHandle:undefined}); JSON encoding of that context would contain only `{"referenceSequenceNumber":0}`. Protocol subtree and pending formats are specified in sibling chapters. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/attachment.ts:148-211`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1594-1607`.)

The internal AttachmentData union (not serialized directly) is exactly: `{state:Detached}` → either `{state:Attaching,summary,blobs:"none"}` or `{state:Detached,blobs:"outstanding",redirectTable:Map<localId,storageId>}` → `{state:Attaching,summary,blobs:"done"}` → `{state:Attached}`. Runtime summary with local-to-storage redirects is produced only after uploads finish. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/attachment.ts:23-83`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/attachment.ts:148-219`.)

## 4. Behavior

### Construction and network load: exact order

1. Construct Container while lifecycle=loading. Set up client (default details.capabilities.interactive=true, mode=read, permission=[], scopes=[], user={id:""}; override via structuredClone and merge details/capabilities; environment joins prior environment, loaderVersion and containerId using semicolons). Construct delta manager first and add an extra inbound and signal pause to its own initial pauses; install delta listeners for connect, establishing/cancel, disconnect, throttled, readonly, closed/disposed. Construct connectionStateHandler with restored pendingLocalState.clientId; construct detached blob storage when not attached, storageAdapter with group snapshots and protocol-summary wrapper, then SerializedStateManager. Offline enabled iff interactive and `Fluid.Container.enableOfflineFull??true`. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:893-1008`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1994-2028`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:2043-2129`.)
2. Static load constructs container; default mode `{opsBeforeReturn:"cached"}`; pending state overrides opsBeforeReturn to undefined even if requested. Install temporary closed listener that rejects with supplied error or GenericError `Container closed without error during load`. Invoke private load. Its failure normalizes, closes, disposes and rejects; finally remove temporary closed listener. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:331-380`.)
3. private load awaits createDocumentService(resolvedUrl,logger,isSummarizer); installs metadataUpdate listener if supported. Start socket **before fetching snapshot** only if deltaConnection undefined. Initial mode is write only if `Fluid.Container.ForceWriteConnection===true`, else read; noninteractive/nonreconnecting container forces write. fetchOpsFromStorage=false initially. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1572-1586`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1630-1648`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1551-1557`.)
4. Connect storageAdapter to service; DisableLoadConnectionRetries=true gives storage maxRetries=0 and initial socket max attempts=1. Assign attachmentData={state:Attached} directly (no attaching/attached events on load). Fetch base snapshot/version/attributes through SerializedStateManager. Record loaded version. Pending savedOps final SN, if present, becomes manager baseline P/Q/O; otherwise snapshot attributes SN. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1650-1674`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:2043-2055`.)
5. Install delta handler callbacks early, passing attributes MSN, snapshot SN, baseline P. For opsBeforeReturn undefined: prefetch=none if deltaConnection==none else all, fire without await. For cached/all: retain promise to await later. attachOpHandler releases only manager's pause; container's extra pause still blocks processing. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1675-1702`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:2132-2148`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/deltaManager.ts:594-628`.)
6. Read quorum blobs in parallel from `.protocol` tree or legacy root; construct protocol handler and seed audience. Register quorum error telemetry, codeDetailsProposed for code/code2, and code proposal approval handling; assign handler synchronously. If pending clientId supplied set protocol audience self now; container clientId must still be undefined (0x96d). (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1704-1717`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1887-1956`.)
7. Get code details as `quorum.get("code") ?? quorum.get("code2")`: **code wins**, except null/undefined fall through; there is no validity-based fallback (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:314-315`). Await codeLoader.load(codeDetails), use returned details??requested details, require fluidExport.IRuntimeFactory else Error `Code package does not implement IRuntimeFactory` (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:180`); construct context and instantiateRuntime(context,existing), with pendingRuntimeState??{} if restoring and undefined otherwise. Validate compatibility; assign runtime, emit internal runtimeInstantiated, then record loaded code details. Failure disposes and rethrows. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1719-1727`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:2431-2509`.)
8. Pending restore: for each saved op call processRemoteMessage on copy with metadata spread then savedOp:true, then await runtime.notifyOpReplay?.(originalMessage). This bypasses DeltaManager apply-validation since its baseline already includes these ops; protocol still advances from snapshot SN. After loop replace savedOps=[] and clear adapter pending state. Do not initialize connection-state membership before this replay. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1729-1742`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:494-501`.)
9. If not closed and an opsBeforeReturn promise exists: resume container inbound **ops only**, await prefetch promise then inbound.waitTillProcessingDone; pause ops again (without awaiting; increment synchronous). Signals remain held. If still open setLoaded, then handleDeltaConnectionArg. A closed container throws `Container was closed while load()`; success never hands host a silently closed instance. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1744-1779`.)
10. setLoaded if still loading: lifecycle=loaded, assert not Connected 0x969; initProtocol on connectionStateHandler only now; for older runtime lacking setConnectionStatus and not disposed call setConnectionState(false,clientId); if transport already connected obtain details (0x96a) and deliver delayed receivedConnectEvent. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:479-523`.)
11. handleDeltaConnectionArg requires loaded 0x96f. undefined: connect supplied args if present, then fall through delayed. delayed: require inboundQueuePausedFromInit 0x346, clear flag, resume ops then signals. none: neither resume nor connect. Thus delayed permits storage/op processing without opening socket; none holds both queues until explicit connect. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:2652-2688`.)

### Detached create and rehydrate

Create sets attributes `{sequenceNumber:0,minimumSequenceNumber:0}`, attaches delta handler, seeds quorum with code committed at all-zero sequence fields and empty members/proposals, initializes protocol, instantiates runtime without snapshot, then setLoaded. Container's extra pause remains until attach/connect flow releases it. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1805-1827`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/quorum.ts:9-20`.)

Rehydrate detached: if hasAttachmentBlobs and serialized attachmentBlobs exists require detached storage and initialize; require nonempty detached storage whenever flag true. Convert snapshotInfo with snapshotSequenceNumber=0, cache blobs, read document attributes, attach delta handler, read quorumValues only; initialize members/proposals empty and restored values, instantiate runtime from snapshot with pending runtime state, setLoaded. Runtime baseSnapshot is recursively reconstructed as `{...snapshotTree,blobsContents,trees}`: each level maps storage ID (not blob path) to available bytes in `blobsContents`, omits missing bytes, and replaces trees with recursively converted children. Full ISnapshot is also passed separately. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/utils.ts:288-315`.) (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1829-1884`.)

### Attach: state predicates and effects

`attach` is runSingle: same concurrent argument identities share same promise; differing arguments reject `Subsequent calls cannot use different arguments.`. Only lifecycle loaded and attach state not Attached permitted, else UsageError. State updates first replace attachmentData; if enum state changed and new!=Detached, runtime.setAttachState(new) then emit lowercased `attaching`/`attached`; an exception normalizes and closes. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/utils.ts:413-435`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1250-1293`.)

1. If blobs discriminator undefined: test detachedBlobStorage exists&&size>0. True selects Detached/outstanding with empty redirect Map; false synchronously calls createAttachmentSummary and selects Attaching/none; publish state. Summary creation asserts inbound queue empty 0x0d6, calls runtime.createSummary(redirectTable) then captureProtocolSummary and combines them.
2. Await createOrGetStorageService(current.summary). If service absent: resolve request, assert non-summarizer and resolved URL defined 0x2c4; create service in attach mode using createContainer(summary,resolvedUrl,logger,false), through runWithRetry with close abort. DisableCloseOnAttachFailure=true sets maxRetries=0. Connect storage adapter and return it. Existing service reused.
3. Outstanding branch: require detached blob storage 0x24e; while redirectTable.size<storage.size obtain getBlobIds filtered not in map; sequentially readBlob(id), await remote createBlob(bytes), record response.id. Repeat outer loop to catch blobs created during awaits. Generate summary with redirects, switch Attaching/done and publish runtime attaching then host attaching.
4. Require Attaching 0x8e2. done branch uploads summary with refSN=0 and omitted handles; none branch already sent summary during createContainer, so no uploadSummary call.
5. Convert saved combined summary to initial snapshot; publish Attached (runtime then host), return snapshot. Container sets serializer initial snapshot; if not closed disposes detached blob storage, then handleDeltaConnectionArg(attach deltaConnection,{fetchOpsFromStorage:false,reason:{text:"createDetached"}}).

Default failures close via normalized error plus resolved URL telemetry. When `Fluid.Container.DisableCloseOnAttachFailure===true`, generic attach-process rejection is not automatically closed, so retained state enables retry; errors from summary generation and runtime/event attachment transitions still close through their explicit catches. No rollback to Detached. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/attachment.ts:139-220`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1295-1357`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1587-1607`.)

### Explicit connection control

connect closed→UsageError, detached→UsageError; if not already connected, set auto-reconnect Enabled and resume initialization pause if still held (assert loaded 0x96c), then ensure socket, with no prefetch because open path already fetched. disconnect closed→UsageError; otherwise set auto-reconnect Disabled (immediate socket disconnect/cancel), but do not pause incoming ops or discard current inbound state. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1389-1453`.)

### Message/event order and code proposals

For each sequenced message compute local=(container.clientId===message.clientId), protocol.processMessage, runtime.process(message,local), serializer.addProcessedOp, active-writer heuristic/accept, host op. Only fully Connected write sockets are active for heuristic. Client identity promotion must not happen early or old-connection acknowledgements will become remote and pending ops may replay twice. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:2031-2040`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:2348-2392`.)

Code approval first reads currently committed code using code-before-code2, then calls pause on ops and signals in that order and awaits both. Missing loaded module means false. Build comparer list in order: codeLoader.IFluidCodeDetailsComparer if defined, then loadedModule.module.fluidExport.IFluidCodeDetailsComparer if defined. No comparers means false; otherwise await each comparer.satisfies(loadedModule.details,constraintCodeDetails) sequentially, stop on exactly false, return true if all pass (other falsy results do not reject). Compatible resumes ops then signals, incompatible closes GenericError `Existing context does not satisfy incoming proposal`; no codeDetailsChanged event is emitted here. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1491-1548`.)

### Close and dispose: terminal order

Host close delegates to DeltaManager.close while lifecycle is still loaded so the disconnect reaches runtime. Manager marks closed, CM.dispose(error,true): Never, clear outbound, disconnect socket/cancel attempt, then readonly true notification. Container's disconnect listener clears noop debt and calls state handler (loaded) or cancellation (loading). Effective state propagation calls runtime first, then protocol connection state, then host disconnected. Manager aborts fetch/clears and pauses inbound queues/drops pending, emits closed → container.closeCore. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1044-1049`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/deltaManager.ts:789-840`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/connectionManager.ts:388-413`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:2092-2118`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:2211-2250`.)

closeCore asserts not closed 0x315; log close before changing lifecycle; set closing; remove metadataUpdate listener if supported; protocol.close; stateHandler.dispose; serializer.dispose; runtime.close?. An exception in this cleanup group is logged and skips remaining statements in that group, but still emits host closed(error); removes visibility listener; finally lifecycle=closed. Summarizer then calls dispose. **close does not ordinarily dispose runtime/storage/service**. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1075-1122`.)

dispose calls manager.dispose, which sets disposed+closed, disposes CM without readonly switch, clears queues, emits disposed before removing manager listeners. Container.disposeCore asserts not already disposed 0x54c, marks _disposed; set lifecycle disposing unless already closed; protocol.close, state handler dispose, serializer.dispose, runtime.dispose(error===undefined?undefined:new Error(error.message)), storageAdapter.dispose, service.dispose(error), then emit host `disposed(error)`, remove all host listeners, remove visibility listener if present; finally set lifecycle=disposed and emit internal lifecycle `disposed` with no arguments. A cleanup exception logs ContainerDisposeException and skips remaining cleanup statements in the inner try, but still enters host event emission; an exception from host disposed skips listener removal but still executes the final lifecycle block. This is separate from close; static-load failure runs both. Outer verifyClosedAfter nesting counter only asserts final Disconnected (0x0cf) and lifecycle closed/disposed (0x314) when all nested close/dispose calls return. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/deltaManager.ts:808-825`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1052-1071`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1125-1180`.)

## 5. Invariants and asserts

All lifecycle/attach asserts above retain their source codes. Runtime status requires accepted clientId on Connected 0x96e; signal self needs pending ID in CatchingUp 0xc89. Modern runtime status additionally asserts catching-up pending ID 0xc8a, connected ID 0xc8b and accepted==pending 0xc8c. Metadata updates merge into container metadata before host metadataUpdate(metadata). (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:2214-2224`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:2601-2624`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1560-1563`.)

Additional lifecycle guards: connectInternal requires !closed (0x2c5) and Attached (0x2c6); disconnectInternal requires !closed (0x2c7); resumeInternal requires !closed (0x0d9). Transport connect details.mode must equal container.connectionMode (0x4b7). Connection-issue callback requires loaded (0x96b). Runtime instantiation requires no live existing runtime (`_runtime?.disposed !== false`, 0x0dd). Detached rehydrate requires detached store before attachment initialization (0xb8e), then nonempty store if flag true (0x250). (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1405-1445`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:2064-2065`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:943-945`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:2423`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1836-1847`.)

## 6. JS-semantics hazards

Two independent pause owners prevent early delivery. Saved op replay directly enters container while manager sequence already reflects final saved op; replay through manager is incorrect. runtime.setAttachState precedes host event synchronously; a host can close reentrantly during attached. close sets lifecycle closing only **after** transport disconnect, not before. Preserve same-promise single-flight identity for attach. (`reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1729-1742`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1279-1293`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/container.ts:1044-1049`, `reference/fluidframework-3.11.0/packages/loader/container-loader/src/utils.ts:413-435`.)
