# routerlicious-driver — Swift port contract (3.11.0)

## Role

Remote document service: creates containers, discovers session placement, opens socket.io delta streams, reads REST deltas, and reads/uploads Git-backed or whole-summary storage. Uses driver-base for socket lifecycle and driver-utils for retries, ordered fetches and prefetch. Source: `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/documentServiceFactory.ts:134-391`, `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/documentService.ts:103-308`.

## Wire and persisted formats

### Socket.io setup and inventory

Open socket at deltaStreamUrl (initial fallback `deltaStreamUrl || ordererUrl`), options `{query:{documentId:id,tenantId},reconnection:false,transports:["websocket"],timeout:20000}`. Handshake deadline=22000 ms (20000+2000), no retry timer reset on transport downgrade. Source: `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/documentDeltaConnection.ts:22-70`, `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/documentServiceFactory.ts:337-340`, `reference/fluidframework-3.11.0/packages/drivers/driver-base/src/documentDeltaConnection.ts:523-527`.

No driverVersion field, nonce or epoch is added by this producer. Missing environment produces a string beginning `; driverVersion:`. Source: `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/documentDeltaConnection.ts:22-60`, `reference/fluidframework-3.11.0/packages/drivers/driver-base/src/documentDeltaConnection.ts:487-490`.

### REST transport common to every endpoint

Let `O=resolvedUrl.endpoints.ordererUrl`, `S=storageUrl`, `L=deltaStorageUrl`, `t=tenantId`, `d=documentId`. REST wrapper concatenates baseURL and URL, not URL relative-resolution. Query uses WHATWG URLSearchParams.set, preserving unrelated parameters and overwriting matching names, skipping undefined. Any caller `retry` query is deleted, then driver adds retry=N after previous failures keyed by `method|URL-without-retry`; success deletes that count. Source: `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/restWrapper.ts:35-48`, `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/restWrapper.ts:133-169`, `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/queryStringUtils.ts:6-23`.

Logical headers: host request headers first, then `x-driver-version: driverVersion`, `Authorization` overwritten from token. Orderer Authorization is **`Basic <jwt>`**; storage Authorization is **`Basic <base64(UTF8(tenantId+":"+jwt))>`**. Driver does not create a correlation ID header: `x-correlation-id` is read from responses and logged as requestCorrelationId; caller-supplied headers would be preserved before overrides. `content-length` becomes numeric contentsize; response content-encoding/type are logged. Source: `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/restWrapper.ts:80-106`, `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/restWrapper.ts:290-301`, `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/restWrapper.ts:342-360`, `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/restWrapper.ts:401-413`, `reference/fluidframework-3.11.0/server/routerlicious/packages/services-client/src/constants.ts:10-15`.

**Default actual HTTP is RestLess**: every logical method becomes POST to the same URL/query; actual Content-Type=`application/x-www-form-urlencoded;restless`; no actual Authorization or x-driver-version headers remain. Form pairs in order: `method=<original uppercase method>`, then repeated `header=<key>: <value>` for each logical header in JS object order, then `body=<JSON.stringify(originalBody)>` iff original body truthy and method post/put/patch. URLSearchParams form encoding means spaces `+`, literal plus `%2B`, colon `%3A`. Example logical delta GET with JWT `abc` produces:

```text
POST /deltas/t/doc?from=9&to=20&fetchReason=
Content-Type: application/x-www-form-urlencoded;restless

method=GET&header=x-driver-version%3A+3.11.0&header=Authorization%3A+Basic+abc
```

When RestLess=false, requestInit has method, headers, **body=requestConfig.data with no JSON.stringify or automatic application/json header**. POST object conversion is therefore Fetch's body conversion, not an Axios JSON transformer. Do not silently attribute Axios's behavior to this version. Source: `reference/fluidframework-3.11.0/server/routerlicious/packages/services-client/src/restLessClient.ts:38-69`, `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/restWrapper.ts:40-48`, `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/restWrapperBase.ts:59-82`.

All calls read response.text completely, then JSON.parse iff content-type contains the case-sensitive substring `application/json`, before checking HTTP status. Invalid JSON throws before status mapping/count increment. Success if response.ok OR status===expected (GET 200, POST 201). `IR11sResponse={content:T,headers:Map<string,string>,requestUrl:string,propsToLog:{contentsize?,requestCorrelationId?,contentEncoding?,contentType?,bodySize:number,receiveContentTime:number,parseTime:number,fetchTime:number}}`; bodySize is JS UTF-16 text.length. Source: `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/restWrapper.ts:215-247`, `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/restWrapperBase.ts:26-82`.

## Behavior

### Token and REST request state machine

States token absent (optional initial promise), token cached; request active, waiting429, completed/failed. getToken returns cached if defined; else await initial tokenP or fetchRefreshedToken() with refresh omitted, set token, clear tokenP. No proactive JWT expiry decoding. Every attempt regenerates headers. On fetch rejection increment retry counter; TypeError/FetchError message=`NetworkError: ${message}` and retryable; other rejection safe-stringified and retryable only if resulting message starts NetworkError; matching substring `failed, reason: self signed certificate` → nonretryable sslCertError. Source: `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/restWrapper.ts:171-207`, `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/restWrapper.ts:290-316`.

HTTP failure after body parsing: increment counter; if status===401 AND canRetry, fetch token(true), recurse with canRetry=false. If 429 AND body.retryAfter>0, wait retryAfter*1000, recurse with default canRetry=true, **without max attempts** (this resets one-401 budget). Otherwise map status below. Neither Retry-After header nor body.retryAfterMs is used by this REST path. Source: `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/restWrapper.ts:250-287`.

| Status | Error mapping after internal retries |
|---|---|
| 401,403 | AuthorizationError, canRetry=false |
| 404 | NonRetryableError(fileNotFoundOrAccessDeniedError) |

## JS-semantics hazards

Do not merge storage/orderer auth; RestLess wraps auth as form fields, not headers. Preserve object insertion order and encodeURIComponent per-component; WHATWG pathname returns percent escapes and getAbsoluteUrl/resolved IDs can be double encoded elsewhere. Null, undefined and empty strings take different branches (`||` versus `??`). Socket queues must live on serial executor across handshake promise completion; no dedup in driver-base. Preserve SHA dedup insertion before awaited upload, Promise.all entry order, and the whole cache race side effects. Byte counts differ from JS UTF-16 telemetry lengths. REST retryAfter units differ across internal429 wait, terminal mapping and socket errors; do not accidentally consolidate them into one conversion.
