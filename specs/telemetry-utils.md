# telemetry-utils (client dependency contracts)

## 1. Role

Shared client diagnostics, trusted-error normalization, typed configuration and feature-gate lookup. Logger output is host telemetry, not Fluid protocol traffic; no summary content is owned by this package. Errors can control close/retry behavior in callers, so normalization must preserve retry metadata and trusted identity rather than merely converting errors to strings. (reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/errorLogging.ts:117-172, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/config.ts:193-268, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/logger.ts:283-338.)

## 3. Wire and persisted formats

None for Fluid ops/summaries. Host telemetry base events have `{category:string,eventName:string,[property]:string|number|boolean|undefined|Tagged}`; standard categories generic/error/performance. Extended logger events accept flat objects/arrays, converted to JSON **strings**. Tagged values are `{value:convertedValue,tag:string}`. Example `sendTelemetryEvent({eventName:"Example",count:2,details:{id:3}})` sends `{"category":"generic","eventName":"Example","count":2,"details":"{\"id\":3}"}` at essential level. Namespace `ContainerRuntime` changes eventName to `ContainerRuntime:Example`. This is not a service signal. (reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/logger.ts:283-318, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/logger.ts:365-403, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/logger.ts:952-1005.)

Error discriminators are literal `genericError`, `usageError`, `dataCorruptionError`, `dataProcessingError`, `layerIncompatibilityError`. GenericError has optional error (excluded from telemetry); UsageError telemetry `usageError:true`; corruption `canRetry:false,dataProcessingError:1`; processing `canRetry:false`; layer error includes string layer/layerVersion/incompatibleLayer/incompatibleLayerVersion/details, numeric compatibilityRequirementsInMonths/actualDifferenceInMonths and layerIncompatibilityError=true. No serialized stack format is part of Fluid interoperability. (reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/error.ts:166-211, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/error.ts:246-252, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/error.ts:309-348.)

Message-safe property projection order: `{messageClientId,messageSequenceNumber,messageClientSequenceNumber,messageReferenceSequenceNumber,messageMinimumSequenceNumber,messageTimestamp}`; clientId=null becomes string `"null"`, undefined stays undefined. No message payload is included. Example message `{clientId:null,sequenceNumber:9}` gives JSON `{"messageClientId":"null","messageSequenceNumber":9}` after undefined omission. (reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/error.ts:358-374.)

Config values are number/string/boolean or homogeneous arrays thereof, or undefined. String inputs may simultaneously expose original string/raw and parsed typed value: `"true"` → raw/string `"true"`, boolean true; `"42"` → raw/string `"42"`, number 42; `"[1,2]"` → number array plus original string; `"[]"` → raw/string only (empty arrays have no first primitive type); `"null"` → raw/string only. Actual []/null/object input has no accepted typed value and allows trying next provider; actual heterogeneous array invalid. JSON-quoted input `"\"foo\""` yields getString `foo` (parsed primitive overwrites fallback string), raw remains JSON-quoted text. (reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/config.ts:103-151.)

## 4. Behavior

### LoggingError and normalization transitions

LoggingError constructor creates UUID v4 `_errorInstanceId`, Error(message), omission set containing omission-set name, internal ID and cause; optional props fill only fields whose current value === undefined. Existing defined value (including null/false/0) wins. getTelemetryProperties enumerates own enumerable properties excluding omission set, converts each to base property type; then returns spread properties plus stack,message,errorInstanceId in that order. GenericError additionally omits its nested error field. (reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/errorLogging.ts:86-94, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/errorLogging.ts:396-481, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/error.ts:175-184.)

normalizeError:

1. Already isFluidError: add annotations.props (fill undefined only), return exact same object.
2. Otherwise extract safe message as error.message if string, else JS String(error); stack only for non-null, non-array object with string stack; create NormalizedLoggingError with genericError type and a new UUID; preserve original stack if string.
3. If original non-null object has `canRetry`/`retryAfterSeconds` properties (using `in`, no type check), copy their values to normalized error. These are operational retry fields, not merely telemetry annotations.
4. For typeof original != object add typeofError; for LoggingError-shaped original copy its telemetry properties, otherwise add untrustedOrigin:1; merge annotations over this temporary properties object, then add to normalized error without overwriting defined properties.

(reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/errorLogging.ts:21-72, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/errorLogging.ts:117-172, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/errorLogging.ts:497-508.)

wrapError extracts original message/stack, constructs supplied error, assigns cause=inner; copies stack if present; marks untrustedOrigin when isExternalError; when inner has string errorInstanceId **overwrite new ID with it** and add innerErrorInstanceId same value; copy logging properties last. wrapErrorAndLog then emits WrapError using errorInstanceId and wrappedByErrorInstanceId, both equal the preserved ID, with original error attached. isExternalError: non-LoggingError shape true; trusted normal LoggingError false; normalized genericError external iff telemetry untrustedOrigin===1 or Boolean(errorRunningExternalCode). (reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/errorLogging.ts:235-308, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/errorLogging.ts:334-347.)

DataProcessingError.wrapIfUnrecognized: build props `{dataProcessingError:1,dataProcessingCodepath:codepath,...safeMessageProjection}`; normalize original with props. If external or normalized.errorType===genericError, wrap into DataProcessingError and add normalized telemetry; otherwise return normalized recognized error without replacing its type. create variants for corruption/processing run same helper from errorMessage, add caller props, and restore temporary Error.stackTraceLimit in finally. validatePrecondition falsy throws UsageError, not assertion. (reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/error.ts:50-105, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/error.ts:131-158, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/error.ts:217-232, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/error.ts:258-299.)

### Configuration resolution transitions

CachedConfigProvider construction breadth-first flattens nested CachedConfigProviders by queueing their orderedBaseProviders at the **end** of candidate queue; deduplicates providers by object identity and ignores missing/non-provider entries. This can reorder nested vs later direct providers: Cached(A),B becomes B,A, not A,B. For a first key read, consult ordered providers until stronglyTypedParse returns an accepted record; cache it; emit ConfigRead with tagged configName and configValue=JSON.stringify(parsed) at info. Cache missing result `{raw:undefined}` without logging. All subsequent typed/raw getters use cached record forever; changing base config does not refresh already-read keys. A provider returning an accepted string of the wrong desired type blocks later providers; typed lookup does not continue based on requested type. (reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/config.ts:193-268.)

Parsing algorithm: start output=input; if input string try JSON.parse and on success remember `{raw:input,string:input}`; primitive result returns record including raw=input and corresponding typed result. Homogeneous nonempty array accepts primitive element type; empty/mixed/nonprimitive arrays return fallback string record or undefined. Object/null parsed from string similarly retains fallback string. inMemoryConfigProvider reads Storage.getItem under try/catch, typed-parses and returns its `.raw`, then wraps in cache; missing storage uses null provider. sessionStorage access exceptions are swallowed. wrapConfigProviderWithDefaults is `original?.getRawConfig(name) ?? defaults[name]`, so false/0/empty-string do not select default. (reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/config.ts:37-64, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/config.ts:103-187.)

loggerToMonitoringContext returns existing context if config has getRawConfig and logger exists; otherwise mutates logger with `.config=new CachedConfigProvider(logger,...configs)` and `.logger=logger`, using sessionStorage as default. mixin on existing context throws. ChildLogger propagates parent config into a new cache; createChildMonitoringContext combines child creation and this conversion. OptionsProxy freezes empty target; access property calls matching reader(config,namespace+"."+property), falls back to default only for undefined. `in` tests union of reader/default keys, and enumeration throws `OptionsProxy keys are not enumerable`. (reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/config.ts:291-417, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/logger.ts:493-512.)

### Literal feature gates

| Key | Consumer and branch |
|---|---|
| `Fluid.Container.ForceWriteConnection` | Azure and Tinylicious clients provide true default. Tinylicious no user config input; Azure wraps supplied provider. This is a loader connection policy, not a telemetry transmission flag. |
| `Fluid.Telemetry.DisableSampling` | createSampledLogger reads boolean once (default false); true bypasses sampling unless skipLoggingWhenSamplingIsDisabled=true, which instead suppresses events. False runs eventSampler.sample(), or sends all if sampler absent. Same rule on all logger methods. |
| `Fluid.AllowIncompatibleLayers` | true bypasses incompatible layer error/disposal, logs LayerIncompatibilityDetectedButBypassed once per module/session. Missing compatibility details with non-strict check independently bypasses/logs once per validating-target layer pair. Otherwise log LayerIncompatibilityError, call disposeFn(error), then throw same error. |

These are literal case-sensitive keys; config does not strip Fluid prefix or perform hierarchical lookup. Other packages define their own key names; this provider resolves the exact string passed, with no registry of allowable flags. ### Logger interfaces and event order

Base logger interface requires synchronous `send(event,logLevel)` with optional minLogLevel; extended implementations permit omission and default to essential. Log levels are verbose=10, info=20, essential=30. (reference/fluidframework-3.11.0/packages/common/core-interfaces/src/logger.ts:63-125.) Extended logger methods sendTelemetryEvent(event,error?,level?), sendErrorEvent(event,error?), sendPerformanceEvent(event,error?,level?). Telemetry/performance default category generic/performance unless supplied; error category forces essential. All default to essential, not info. Extended event conversion starts category,eventName then converted extra own keys. If error supplied, prepareErrorObject overwrites event.stack/error/errorType with sanitized stack/message/type, then fills missing event fields from error.getTelemetryProperties; sanitize removes first stack line and prepends error.name if string. Numeric duration is floored by formatTick. Finally send synchronously. (reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/logger.ts:198-200, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/logger.ts:230-260, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/logger.ts:283-363, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/logger.ts:952-1005.)

ChildLogger prepares cloned event, prefixes namespace with `:`, fills missing properties from `.all` then `.error` when category error or event.error defined; getter values run only when event field undefined. Child of Child flattens namespace/property bags: child properties overwrite parent within corresponding bag, but event properties beat both. Absent logger becomes no-op sink. Before preparation filter `eventLevel < (base.minLogLevel ?? info)`; event level omitted → essential. MultiSink prepares once and sends same object to each sink in array order, no internal per-sink filtering; computes minLogLevel as min of sink levels (default info), or info when none. (reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/logger.ts:365-403, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/logger.ts:454-536, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/logger.ts:597-660.)

EventEmitterWithErrorHandling runs superclass synchronous emission inside one try/catch. First throwing listener aborts the rest of that emission, calls errorHandler(event,error), returns true if handler returns; if handler throws, propagates. Do not continue dispatching later listeners as if every callback had its own catch. (reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/eventEmitterWithErrorHandling.ts:31-37.)

## 6. JS-semantics hazards

Preserve missing vs undefined vs null and property existence tests; copies must not overwrite defined fields or discard unusual retry metadata. String(error) uses JS conversions (undefined→"undefined", null→"null", objects typically→"[object Object]"). Do not implement typed config as simple Bool(String): original strings can expose multiple typed projections, empty arrays do not resolve, negative results cache. UUID identity survives wrapping; error-instance ID is not a type discriminator. Logger methods and event handler error paths are synchronous. Object JSON property ordering and stringify number/nonfinite semantics apply to emitted nested strings. (reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/errorLogging.ts:50-72, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/errorLogging.ts:86-94, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/errorLogging.ts:137-170, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/errorLogging.ts:263-267, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/config.ts:103-151, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/config.ts:244-268, reference/fluidframework-3.11.0/packages/utils/telemetry-utils/src/logger.ts:984-1005.)
