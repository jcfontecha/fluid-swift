# container-runtime / garbage collection

## 1. Role

Tracks document graph reachability, unreferenced ages, tombstones and sequenced deletion. It does not use native object lifetime or Swift ARC to decide document retention. Runtime supplies graph, node taxonomy and route updates/deletion callbacks. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcReferenceGraphAlgorithm.ts:15-51` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:605-646`

## 3. Wire and persisted formats

The root subtree is **`gc`**, not `.gc`. Keys: `__gc_root` for current writer's graph, `__tombstones`, `__deletedNodes`. Reader accepts all blobs beginning `__gc` and merges graph partitions, ignoring unrelated keys; tombstone/deleted keys read separately. `__gc_root` is JSON `{gcNodes:{"/path":{outboundRoutes:["/path",...],unreferencedTimestampMs?:number},...}}`. Tombstones/deleted are JSON arrays of absolute node paths; empty lists omit their blobs. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcSummaryStateTracker.ts:27` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcSummaryDefinitions.ts:12-46` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcHelpers.ts:182-216` `reference/fluidframework-3.11.0/packages/runtime/runtime-definitions/src/garbageCollectionDefinitions.ts:11-29`

Writer sorts graph node entries with JS `a.localeCompare(b)`, sorts each outboundRoutes with default JS `.sort()`, and emits node fields `outboundRoutes` then optional timestamp. Deleted paths sort default; tombstones sort default in place. In non-full tracked summaries unchanged whole state emits Tree handle `/gc`; otherwise each unchanged component emits Blob handle `/gc/<key>`, changed components emit blobs, in graph/tombstone/deleted insertion order. Baseline advances only on tracked ack refresh. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcHelpers.ts:83-95` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:888-902` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcSummaryStateTracker.ts:98-152` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcSummaryStateTracker.ts:165-229`

Metadata fields in order: `gcFeature` (active version, or 0 when disallowed), `gcFeatureMatrix?`, `sessionExpiryTimeoutMs?`, deprecated `sweepEnabled:false`, `tombstoneTimeoutMs?`. Stable GC version 3; feature-gated next version 4. Existing missing metadata/gcFeature means GC disabled. On mismatched GC version discard graph/tombstones but **retain deleted nodes**. Missing legacy root gc tree resets old state instead of reading per-store legacy GC as current state. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:905-916` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcDefinitions.ts:37-41` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcConfigs.ts:66-78` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:240-260`

GC ops are `{type:"GC",contents:{type:"Sweep",deletedNodeIds:[...]}}` or `{type:"GC",contents:{type:"TombstoneLoaded",nodePath:"/..."}}`, property order as shown. Sweep wire list omits DDS nodes and includes datastore/blob nodes only. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:758-774` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:1106-1113`

### Literal GC tree and operation examples

For root referencing `/a`, unreferenced `/b` since server time100, tombstone `/b`, and permanently deleted `/c`, full subtree is:

```json
{"type":1,"tree":{"__gc_root":{"type":2,"content":"{\"gcNodes\":{\"/\":{\"outboundRoutes\":[\"/a\"]},\"/a\":{\"outboundRoutes\":[]},\"/b\":{\"outboundRoutes\":[],\"unreferencedTimestampMs\":100}}}"},"__tombstones":{"type":2,"content":"[\"/b\"]"},"__deletedNodes":{"type":2,"content":"[\"/c\"]"}}}
```

Attach that tree under root `gc`. Unchanged tracked state returns `{"type":3,"handle":"/gc","handleType":1}`. If only tombstones change to empty, emit a tree with graph handle `{"type":3,"handle":"/gc/__gc_root","handleType":2}`, omit `__tombstones` entirely (not `[]`, not its previous handle), and retain deleted-nodes handle `{"type":3,"handle":"/gc/__deletedNodes","handleType":2}`. FullTree disables both tree/blob handle reuse. No previous GC run or shouldRunGC false omits subtree; gcAllowed false also returns no summary. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcSummaryStateTracker.ts:88-216` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:879-902`

Sweep op example `{"type":"GC","contents":{"type":"Sweep","deletedNodeIds":["/b","/_blobs/blobA"]}}`; recovery `{"type":"GC","contents":{"type":"TombstoneLoaded","nodePath":"/b"}}`. DDS routes may be marked unreferenced but are not included directly in a Sweep proposal; datastore deletion expands them on receive. The pending manager does not support stash-applying GC ops. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:758-774` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:933-1009` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:1106-1113` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/containerRuntime.ts:3105-3113`

Historical GC partition blobs use the same `{gcNodes:{...}}` shape under any `__gc` prefix; for duplicate nodes, assert `0x5d7` if both timestamps defined and unequal; choose incoming timestamp when defined, otherwise existing. Routes deduplicate by Set with incoming partition routes before existing routes, retaining that order until summary sorting. Legacy per-datastore details shape is `{usedRoutes?:string[],gcData?:{gcNodes:{[id:string]:string[]}},unrefTimestamp?:number}` under its GC details blob; current root-based loader resets if root gc tree absent, so these details must not be mistaken for current root gc graph nodes. Version mismatch discards graph/tombstone state but deleted-node list survives. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcHelpers.ts:101-141` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcHelpers.ts:182-216` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcSummaryDefinitions.ts:49-65` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:240-260`



## 4. Behavior

### Configuration and initialization

New containers default to session expiry 30 days unless flag explicitly false; inactive timeout 7 days; tombstone timeout is session expiry + max snapshot cache 5 days + 1-day buffer, undefined if no session expiry; sweep grace defaults 1 day. Existing documents preserve persisted session/tombstone values, using legacy `sweepTimeoutMs` as fallback. Inactive must not exceed tombstone; grace must be nonnegative. Sweep enabled iff GC allowed, tombstone timeout defined, app enableGCSweep true and generation compatible. Missing session generation permits sweep; otherwise compare persisted legacy tombstoneGeneration first, else gcGeneration. Tombstone load throwing requires sweep enabled, non-summarizer, and no disable-throw flag. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcDefinitions.ts:75-87` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcConfigs.ts:66-163` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcConfigs.ts:177-184` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcHelpers.ts:65-77`

Load deleted/tombstone state before use; initialize per-node age tracking only with server reference time. Version mismatch must not resurrect deleted content. GC state from first/detached/pre-GC summary may be absent. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:240-300` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:392-414`

### Mark, age and sweep

1. Obtain graph and traverse from `/` with a visited set, following route arrays and handling cycles. Referenced/unreferenced output arrays iterate `Object.keys(referenceGraph)`, not traversal order; missing route targets are visited but absent from result arrays. `deletedNodeIds` in this algorithm means *currently unreferenced*, not physically deleted. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcReferenceGraphAlgorithm.ts:15-51`
2. To avoid aging nodes that were briefly referenced between runs, union previous/current graph plus all explicitly added routes since prior run, then traverse from `/` **and every newly added target**. Clear trackers for that superset's referenced nodes, then mark today's unreferenced nodes afresh or update their existing age. Thus a briefly referenced but now-unreferenced node resets its timestamp. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:796-871` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:663-705`
3. Each tracker stores original unreferenced timestamp and derives age from server reference timestamp, clearing/restarting wall-clock timers for remaining durations. Thresholds: age >= tombstone+grace → SweepReady; else >=tombstone → TombstoneReady plus remaining sweep timer; else >=inactive → Inactive plus tombstone timer; otherwise restart inactive timer. Timer callbacks transition Active→Inactive→TombstoneReady→SweepReady. Removing a tracker stops all timers. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcUnreferencedStateTracker.ts:34-42` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcUnreferencedStateTracker.ts:94-174`
4. Runtime receives current referenced routes after mark. New unreferenced trackers are created but not included in ready sets until later updates; do not eagerly sweep a newly created tracker during that loop. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:676-705`
5. Test mode deletes all current unreferenced nodes immediately. Normal mode updates tombstones to tombstone-ready only if sweep enabled; otherwise include both tombstone-ready and sweep-ready. If enabled, send Sweep op for sweep-ready datastore/blob nodes. **Do not delete during GC run**; physical logical deletion occurs on processing sequenced Sweep. Clone current graph for next run after sweep phase. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:631-637` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:721-774`
6. Every client executes received Sweep regardless of its own sweep configuration. Expand datastore paths to known subnodes using unreferenced trackers; call runtime deletion; clear trackers and add only callback-returned deleted nodes to permanent deleted set. Unknown GC op type throws. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:933-1009`

### Tombstone enforcement and recovery

Node usage is telemetry-tracked when GC enabled and timestamp exists. Tombstoned Loaded usage triggers recovery before load failure decision. Only Loaded blob/datastore paths can throw 404 tombstoned response, only if configured and allowTombstone not true. Summarizer does not enforce that load failure. With sweep enabled, recovery submits TombstoneLoaded. On processing it add root→node reference at message timestamp and request full GC. Recovery state requested→ran on GC completion→clear on summary ack; continue full GC until that ack, not just first scan. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:1018-1113` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:946-958` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:350-383`

GC feature matrix is absent or `{gcGeneration?:number}` for new documents, or historical `{tombstoneGeneration:number}`. New writer with configured generation5 emits `gcFeatureMatrix:{gcGeneration:5}`; never automatically emit both names. Existing metadata's `sweepTimeoutMs` is a legacy **tombstone** timeout fallback, not the additional sweep grace. GC metadata deprecated `sweepEnabled` is always false on write even when this session can actually sweep. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcDefinitions.ts:93-124` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcConfigs.ts:66-96` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:905-916`

Zero sweep grace: tombstone timer callback sets TombstoneReady and immediately SweepReady without scheduling sweep timer. Undefined tombstone timeout never starts tombstone/sweep timers. updateTracking clears all timers first and chooses >= thresholds using server age; its young-age branch starts inactive timer without explicitly assigning Active, so do not add an undocumented state reset when server time moves backward. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcUnreferencedStateTracker.ts:94-174`



## 5. Invariants and asserts

`0x8a4` initialization requires current reference timestamp; `0x5d8` graph blob must decode; tracker `0x863/0x864` later timer cannot fire with earlier-stage timers still running. Configuration rejects inactive>tombstone and grace<0. Deleted state survives even if graph version doesn't. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:279-284` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcHelpers.ts:211-214` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcUnreferencedStateTracker.ts:94-107` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcConfigs.ts:129-143` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/garbageCollection.ts:251-260`

## 6. JS-semantics hazards

Default string sort is UTF-16 code-unit lexicographic, while node-key sort uses localeCompare: these are **not interchangeable**, nor equivalent to Swift String `<`. Route sorting mutates arrays; dictionary ordering follows JS property order. Keep missing timestamp distinct from 0; undefined blobs omit, not JSON null. GC aging uses server time, but timers and session expiry use wall-clock elapsed time—never replace both with local timestamps on reload. Mark-result “deleted” must never be confused with persistent actual deleted set. `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcHelpers.ts:83-95` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcSummaryStateTracker.ts:98-105` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcReferenceGraphAlgorithm.ts:40-51` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/containerRuntime.ts:4538-4541` `reference/fluidframework-3.11.0/packages/runtime/container-runtime/src/gc/gcUnreferencedStateTracker.ts:132-174`
