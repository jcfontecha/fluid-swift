## Role

Shared loader/driver support: ordered asynchronous delta streams, retry/error policy, storage delegation and prefetch, snapshot/summary conversion, optional blob compression, and URL/cache helpers. ## Wire and persisted formats

### Stream and error records

No REST/socket request originates in the parallel/retry/prefetch helpers: their callbacks do I/O. `IDeltasFetchResult={messages:SequencedMessage[],partialResult:boolean}` becomes internal `{partial:boolean,cancel:boolean,payload:SequencedMessage[]}`; `IStreamResult<T>` is `{done:false,value:T}` or `{done:true}`. These flags are not persisted. Example callback result `{messages:[op10,op11],partialResult:true}` becomes `{payload:[op10,op11],cancel:false,partial:true}`, then one stream read `{done:false,value:[op10,op11]}`. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/parallelRequests.ts:354-367`, `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/parallelRequests.ts:418-452`.

Errors carry `message`, exact `errorType`, `canRetry`, and telemetry properties including `driverVersion:string|undefined`; they are not an HTTP response schema. `ThrottlingError` exposes `retryAfterSeconds:number`; accessors return seconds only when typeof is number (no finite/nonnegative guard), and milliseconds are seconds*1000. Generic error factory converts `{canRetry:true,retryAfterMs:1000}` to `ThrottlingError(...,1,props)`; with canRetry false it returns GenericNetworkError and discards delay. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/network.ts:47-67`, `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/network.ts:209-282`.

### Snapshot and detached-tree representations

`ISnapshotTree` contains `id?:string`, `blobs:Record<decodedName,blobId>`, `trees:Record<decodedName,ISnapshotTree>`, optional `unreferenced:true,groupId:string`; Git hierarchy root is inserted `{id:flatTree.sha,blobs:{},trees:{}}`, children `{id:entry.sha,blobs:{},commits:{},trees:{}}`. Path lookup keys remain encoded, final property names are decodeURIComponent. Example flat `{sha:"root",tree:[{path:"a%20b",type:"blob",sha:"b"}]}` yields `{id:"root",blobs:{"a b":"b"},trees:{}}` and SHA map `b -> "/a%20b"`. No sorting; parents must precede descendants. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/protocol/gitHelper.ts:72-103`.

`convertSummaryTreeToSnapshotITree` emits `{entries:ITreeEntry[],unreferenced?:true,groupId?:string}` in that property order; optional metadata copied iff !==undefined. Blob constructor fields are path,mode=`"100644"`,type=`"Blob"`,value=`{contents:string,encoding:"utf-8"|"base64"}`; tree constructor path,value,mode=`"040000"`,type=`"Tree"`; attachment constructor path,id,mode=`"100644"`,type=`"Attachment"`,value=`{id:string}` (parameter properties before field initializers in this TS target). Summary enum values are Tree=1,Blob=2,Handle=3,Attachment=4; ITree entry types are the capitalized strings, not summary enums. Strings remain UTF-8 strings, bytes become base64. Combined `.protocol`/`.app` root is flattened protocol entries first then app entries, renaming **every** `attributes` key to `.attributes` in this combined branch. Otherwise iterate root Object.entries. Nested trees recurse; handles throw `Should not have Handle type in summary tree`. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/treeConversions.ts:19-71`, `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/blob.ts:13-73`, `reference/fluidframework-3.11.0/packages/common/driver-definitions/src/protocol/storage.ts:26-105`.

Concrete converted single blob: `{entries:[{path:"x",mode:"100644",type:"Blob",value:{contents:"hi",encoding:"utf-8"}}]}`. `buildSnapshotTree` flattens this depth-first, creates a fresh UUID for each blob, stores decoded bytes in caller blobMap, uses empty SHA for trees/root, blob size0 and tree size-1, then builds Git hierarchy. Attachments are not flattened by that helper. Thus UUID injection is needed for deterministic fixtures. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/buildSnapshotTree.ts:20-98`.

### Optional compression format

Default config `{algorithm:1,minSizeToCompress:500}`. Prefix bytes are **0xB0 | algorithm**, not raw 0/1: `0xB1` + lz4js compressed frame, or `0xB0` escape + original bytes when uncompressed original starts with high nibble 0xB. No prefix is added for ordinary uncompressed bytes. Empty stays empty. Examples with algorithm None: `[0x61] -> [0x61]`; `[0xB1,0x61] -> [0xB0,0xB1,0x61]`. Size comparison is byteLength < threshold (500 bytes is compressed under defaults), no “compressed result must be smaller” check. Recognize prefix by `(firstByte & 0xF0)===0xB0`, decode low nibble; 0 returns stripped bytes,1 decompresses remaining frame, others throw `Unknown Algorithm N`. JS undefined first byte bitwise-coerces to0 for empty buffers. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/adapters/compression/compressionTypes.ts:9-25`, `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/adapters/compression/summaryblob/documentStorageServiceSummaryBlobCompressionAdapter.ts:66-118`, `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/adapters/compression/summaryblob/documentStorageServiceSummaryBlobCompressionAdapter.ts:192-239`.

`compressSummary` first **mutates input**: depth-first Object.entries search for the first `.metadata` blob's containing tree, inserts/replaces `.metadata.blobHeaders:{type:2,content:""}`. Then recursively copy-on-write replace every summary blob with `{type:2,content:Uint8Array}` after encoding; strings TextEncoder UTF-8 first. Marker presence alongside `.metadata` in any snapshot subtree enables decoding globally on subsequent readBlob/downloadSummary; its content is not fetched to decide. Legacy snapshots without marker return raw bytes even if first byte is 0xB1. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/adapters/compression/summaryblob/documentStorageServiceSummaryBlobCompressionAdapter.ts:128-179`, `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/adapters/compression/summaryblob/documentStorageServiceSummaryBlobCompressionAdapter.ts:253-465`.

### Resolver REST endpoint and cache key format

`InsecureUrlResolver` cross-host resolution: actual POST `${hostUrl}/apis/load`, no query added, headers in order `Authorization: Bearer <bearer>`, `Content-Type: application/json`, **no generated correlation header**, JSON body `{"url":"<request.url>"}`; response is parsed `IResolvedUrl={type:"fluid",id:string,url:string,tokens:Record<string,string>,endpoints:Record<string,string>}`. Non-2xx throws plain Error `HTTP error! status: N`, otherwise response.json; no refresh/retry/status-class mapping. Promise cached by exact original request.url, including rejections forever. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/insecureUrlResolver.ts:42-85`.

Cache key: `${entry.file.docId}${fileVersion===undefined?"":"_"+fileVersion}_${entry.type}_${entry.key}`; no escaping. Examples docId=d,type=snapshot,key=latest => `d_snapshot_latest`; fileVersion=v => `d_v_snapshot_latest`; empty fileVersion adds a literal underscore. Maximum cache duration constant=432000000 ms (5 days), not a timer implemented in this helper. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/cacheUtils.ts:8-27`.

## Behavior

### ParallelRequests state machine (all ranges [from,to))

Initial state working; latestRequested=nextToDeliver=from; knewTo captures whether constructor to was defined and **never changes**; results map empty, inFlight=0. `run(c)` asserts c>0 and working, calls addRequest c times then dispatch; returns terminal promise. Allocation stops if not working or known to<=latestRequested; otherwise allocates up to payloadSize, caps at known to, advances latestRequested before starting callback. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/parallelRequests.ts:47-100`, `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/parallelRequests.ts:160-198`.

Worker loop order:

1. Increment inFlight once per worker. While working, assert positive range and current boundary, increment request counter, invoke callback `(requestIndex,from,to,this.to!==undefined,{})`; dispatch buffered earlier results **before awaiting** callback. Callback resolves `{payload,cancel,partial}`. If cancel set, cancel manager. If another callback learned to<=from, assert !knewTo, discard response and break (log GotExtra if payload nonempty). `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/parallelRequests.ts:191-248`.
2. While still working: set fullChunk=requestedLength<=payload.length. Empty response requires !partial and !knewTo. Nonempty response splice first requestedLength into results[from], advance from by its length. Overlong response logs ParallelRequests_Over; array is mutated. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/parallelRequests.ts:250-292`.
3. If !partial && !fullChunk: when !knewTo shrink global to to min(currentTo,from) and break; when knewTo log ParallelRequests_Partial and continue, never infer EOF. If current request to===latestRequested, consume overfetch remainder in requestedLength-sized chunks into results, advance from, rewind/extend latestRequested=from, force fullChunk=true (even for short partial). Otherwise discard overfetch remainder; a short chunk retries its remaining range. If fullChunk allocate next global range; break if none, otherwise replace local from/to and continue. On worker exit decrement inFlight and dispatch. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/parallelRequests.ts:294-340`.
4. Dispatch while working and results[nextToDeliver] exists: remove it, assert length<=payloadSize, increment nextToDeliver by length, invoke responseCallback synchronously. If inFlight==0 assert no remaining results and finish; otherwise if known to reached assert !knewTo and finish without waiting for speculative workers. Finish requires to defined and nextToDeliver>=to, marks done and resolves. Failure while working marks done and rejects; cancel while working marks canceled and resolves. Late results after terminal state do not dispatch; HTTP callbacks aren't physically canceled by manager.cancel(). `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/parallelRequests.ts:83-158`, `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/parallelRequests.ts:339-340`.

Example: from10,to14,batch2,c2 allocates [10,12),[12,14); second response buffers until first arrives, then callbacks emit [10,11] followed [12,13]. With unknown to, short nonpartial [10] for [10,12) learns to11 and terminates at11. Short **partial** [10] doesn't learn EOF. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/parallelRequests.ts:123-180`, `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/parallelRequests.ts:250-340`.

### requestOps, missing ops and streams

`requestOps` returns queue immediately and launches manager. For each batch getSingleOpBatch loops until abort: increment telemetry retry (first1), call get with range and telemetry. Nonempty messages or !strongTo returns immediately with partialResult forwarded. Empty strong response records first-success monotonic timestamp, and a later empty response **>30000 ms** later throws nonretryable genericNetworkError `Failed to retrieve ops from storage (Too Many Retries)` with opsFetchFailure=tooManyRetries. Intervening network errors don't reset that timestamp. Retryable exceptions log GetDeltas_Error and retry; nonretryable propagate. Backoff seed50ms, doubled before each wait (100,200,400,…), uses same 8000/60000 cap as runWithRetry; after timer wait, wait for `online` event only if navigator.onLine===false and addEventListener exists. No retry count limit. On loop abort return `{partial:false,cancel:true,payload:[]}`. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/parallelRequests.ts:29-30`, `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/parallelRequests.ts:392-526`.

Response callback asserts first sequence==fromTotal or previous last+1, then checks last-first+1==length (does not inspect every interior sequence), updates counters and pushes nonempty batch. Abort listener calls manager.cancel immediately, allowing queue termination without waiting for hung requests; remove listener when run settles. Success logs GetDeltas end, checks final last>=toTotal-1 when bounded, pushes done. Cancellation logs cancel then pushes done (not error); failure logs cancel then pushes rejected stream entry. Already queued values remain ahead of terminal entry. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/parallelRequests.ts:578-664`.

Queue has FIFO promise entries and at most one pending read. pushValue inserts `{done:false,value}`; pushDone inserts `{done:true}` then marks terminal; pushError inserts rejection then marks terminal. A waiting read's deferred is resolved/adopted with pushed promise rather than enqueuing. Read shifts queued item or waits if nonterminal; **reading again after terminal entry is consumed asserts**, unlike emptyMessageStream which always returns done. streamFromMessages awaits one promise then clears it only on fulfillment: empty resolves done, nonempty emits once then done; rejected promise stays rejected on subsequent reads. streamObserver awaits read, calls handler (including done), then returns original value; read rejection bypasses handler, handler throw rejects read. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/parallelRequests.ts:349-389`, `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/parallelRequests.ts:670-714`.

### runWithRetry and rate limiting

1. State success=false,numRetries=0,retryAfterMs=500,start=monotonic now. Invoke api(progress.cancel) immediately **even when already aborted**; it can succeed. On nonretryable catch log `<name>_cancel` and rethrow original before checking abort. Retry is allowed only non-null object with canRetry===true; truthy1/string aren't enough. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/runWithRetry.ts:63-89`, `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/network.ts:258-261`.
2. Retryable catch with cancel.aborted===true logs `<name>_runWithRetryAborted`, throws NonRetryableError(genericError, `runWithRetry was Aborted`,reason,fetchCallName,driverVersion). Otherwise on first retry log firstFailed, increment numRetries; if maxRetries defined and numRetries>maxRetries log maxRetriesExceeded (retry=numRetries-1), wrap original in NonRetryableError(genericError, `runWithRetry failed after max retries: <message>`). maxRetries=0 means only initial attempt. Undefined means unlimited. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/runWithRetry.ts:89-154`.
3. Save lastError; compute `min(max(error.retryAfterSeconds*1000 ?? 0,previousDelay*2), cap)`, where cap60000 iff isFluidError(error) AND getTelemetryProperties().endpointReached===true, else8000. Thus first normal wait1000ms; even a server delay120000 is capped. Call onRetry(delay,error) synchronously; thrown callback aborts unchanged; await delay (not abortable), loop. On success after retries log lastError then return result, even if result undefined. There is **no timeout**, jitter, online waiting or preflight cancel check here. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/runWithRetry.ts:156-203`.
4. RateLimiter is a **FIFO concurrency semaphore**, not requests-per-time. Constructor asserts maxRequests>0; acquire decrements available count if positive else queues resolver. schedule awaits acquire then returns work().finally(release). Release shifts oldest waiter and directly resolves it without incrementing available count, or increments if none. waitQueueLength counts waiting only. Rejected asynchronous work releases; a synchronous throw before work returns its promised value bypasses finally (caller contract is promise-returning). No cancellation/clock/throttle delay. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/rateLimiter.ts:11-45`.

### Prefetch and cache layers

Prefetch state enabled=true, blobId->**Promise** map empty. policies getter: if internal policies truthy return shallow copy overriding caching=NoCaching; otherwise undefined. getSnapshotTree(version) starts inner promise, attaches fire-and-forget then(prefetchTree) if enabled at call time (doesn't recheck flag in continuation), catches derivative failure without swallowing returned original failure, returns original result. It doesn't forward scenarioName. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/prefetchDocumentStorageService.ts:19-48`.

Traverse tree depth-first in Object.entries/values order: for each blob key beginning `.` OR exactly `header` OR beginning `quorum`, immediately call cachedRead iff id!==null and uncached. Other keys not beginning `deltas` and nonnull are appended to secondary list. Recurse trees, then read secondary IDs in collected order, skipping already cached. Thus all priority requests start before any secondary. No local concurrency bound (underlying driver limiter applies). `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/prefetchDocumentStorageService.ts:86-118`.

cachedRead when enabled returns existing promise; otherwise start inner read, attach rejection side effect, put original promise in cache and return it. Retryable rejection deletes **only if map still points to same original promise**; permanent rejection remains cached. All awaiting callers still receive original rejection. stopPrefetch sets false then clears map; doesn't abort pending I/O. Future reads bypass cache. A pending snapshot continuation may still traverse after stop but cachedRead then bypasses cache. No eviction/TTL in prefetch. `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/prefetchDocumentStorageService.ts:51-84`.

R11s backing caches are separate: InMemoryCache stores values, optional MapWithExpiration, NullCache always undefined/no-op put. Keys are docId+":"+resourceId. Expiration is since last **write**, get does not refresh; expires at elapsed>=expiryMs, lazily on get/has/iteration/size; no background timer. set refreshes timestamp; delete/clear update both maps. Prefetch disables loader cache specifically to avoid another redundant layer, not the driver's internal blob/tree caches. `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/cache.ts:8-36`, `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/mapWithExpiration.ts:12-123`, `reference/fluidframework-3.11.0/packages/drivers/routerlicious-driver/src/shreddedSummaryDocumentStorageService.ts:240-243`, `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/prefetchDocumentStorageService.ts:24-28`.
