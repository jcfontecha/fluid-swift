# legacy-dds — SharedArray and SharedSignal (3.11.0)

## Role

SharedArray is an optimistic ordered list whose retained tombstones and move-identity chains support concurrent edits and revertibles. SharedSignal is an op-backed notification channel, **not** the runtime's ephemeral signal transport. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:56-81`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/signal/sharedSignal.ts:86-100`.

## Surface used by other packages

SharedArray kind/factory, SharedArrayClass<T>: create/getFactory/get/insert/insertBulkAfter/delete/move/rearrangeToFront/toggle/toggleMove. get returns a fresh array of nondeleted values. SharedArrayRevertible supports revert()/dispose(); events valueChanged(op,isLocal,array), revertible(revertible). SharedSignal kind/factory/class exposes notify(metadata?), event notify(metadata,isLocal). Factory type strings are `https://graph.microsoft.com/types/SharedArray` (capital S/A) and `https://graph.microsoft.com/types/signal`, snapshot versions both `0.1`. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:90-129`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:175-405`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:776-782`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArrayRevertible.ts:13-50`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArrayFactory.ts:26-38`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/signal/sharedSignalFactory.ts:22-32`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/signal/sharedSignal.ts:166-168`.

## Wire and persisted formats

Array op types are **numbers**, 0 insertEntry, 1 deleteEntry, 2 moveEntry, 3 toggle, 4 toggleMove. Literal producer order/examples:

```json
{"type":0,"entryId":"u1","value":"A"}
{"type":0,"entryId":"u2","value":"B","insertAfterEntryId":"u1"}
{"type":1,"entryId":"u1"}
{"type":2,"entryId":"u1","insertAfterEntryId":"u2","changedToEntryId":"u3"}
{"type":3,"entryId":"u1","isDeleted":false}
{"type":4,"entryId":"u1","changedToEntryId":"u3"}
```

IDs are UUID-v4 strings generated for local insert/new move position (u1 etc abbreviate these strings). insertAfterEntryId optional/omitted for beginning; values arbitrary serializable T (undefined omitted on wire). All other shown fields required. Move creates **new identity for position**, not a new user value. No local op metadata is supplied. SharedObject handles encode recursively as `{"type":"__fluid_handle__","url":"/store/channel"}`. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArrayOperations.ts:9-80`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:207-227`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:310-405`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:757-760`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:798-815`, `reference/fluidframework-3.11.0/packages/dds/shared-object-base/src/serializer.ts:120-162`.

Array has exactly one UTF-8 blob header, no split/version switch. Serializer-stringified `{dataArray:[entry,...]}` in physical array order, including **all tombstones**. Persisted entry fields constructed entryId,value,isDeleted,prevEntryId,nextEntryId; undefined fields disappear. Example after moving A from u1 to u3: `{"dataArray":[{"entryId":"u1","value":"A","isDeleted":true,"nextEntryId":"u3"},{"entryId":"u2","value":"B","isDeleted":false},{"entryId":"u3","value":"A","isDeleted":false,"prevEntryId":"u1"}]}`. Empty `{"dataArray":[]}`. Each value is first serializer.stringify→JSON.parse; undefined top-level value therefore causes JSON.parse failure during summary rather than merely omitting value. Build copies first; then **mutate all live entries' flags** isAckPending=false,isLocalPendingDelete=0,isLocalPendingMove=0; then serialize snapshot. isRollback isn't cleared by unsetLocalFlags and isn't persisted. Load serializer.parse(header), assign dataArray, rebuild ID map and clear those three flags without events; no historical branch. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:132-172`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:507-521`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:846-850`.

Signal op in field order type,metadata: `{"type":"signal","metadata":{"n":1}}`; metadata optional (undefined omitted). Exactly one UTF-8 header containing the two bytes `""` (JSON empty string), no split. Loader ignores storage entirely. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/signal/sharedSignal.ts:92-130`.

Handle encoding additionally permits required-type/url plus optional final `payloadPending:true`: `{"type":"__fluid_handle__","url":"/store/blob","payloadPending":true}`. It is emitted only when the internal handle has payloadPending===true; otherwise the field is absent, never false. Decoder recognizes any value whose type property equals the marker (not a structural url validator), resolves relative URLs against serializer context, and constructs a remote handle with pending flag iff payloadPending===true. User objects with this marker therefore decode as handles rather than ordinary data. `reference/fluidframework-3.11.0/packages/runtime/runtime-utils/src/handles.ts:31-56`, `reference/fluidframework-3.11.0/packages/runtime/runtime-utils/src/handles.ts:95-105`, `reference/fluidframework-3.11.0/packages/dds/shared-object-base/src/serializer.ts:149-162`.

## Behavior

### Array identity and local operations

State: physical entries array, ID→entry Map, remoteDeleteWithLocalPendingDelete Set. New entry fields are entryId,value,isAckPending=true,isDeleted=false,prevEntryId(optional),nextEntryId=undefined,isLocalPendingDelete=0,isLocalPendingMove=0. No removal/GC of identities in this implementation. A move chain is linked by prev/next; getLiveEntry follows truthy next IDs to tail, even when that tail is deleted. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:64-81`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:824-838`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:907-913`.

Public insert/delete/move reject negative indexes (move checks negatives before no-op). Mapping live deletion index counts only isDeleted===false physical entries; throw if not enough live entries. Insertion index 0→physical 0, otherwise index of (live index-1)+1. move(from,to) no-ops if equal or to=from+1; target is insertion boundary in the original sequence, not final index after removal. insert creates/splices a UUID entry, records physical predecessor as insertAfterEntryId. Delete marks live entry deleted and increments its pending-delete counter. Move creates UUID entry with old value,prev=old ID, marks old deleted,next=new ID, increments old pending-move counter and inserts new at target physical index. Each then emits valueChanged(op,true,array), emits revertible, then submits only if attached. Flags are allocated/updated even detached. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:200-331`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:729-815`.

insertBulkAfter searches from physical last index **while index>0** for nondeleted value===ref; with defined ref adds one to resulting index even if no match (so nonempty no-match yields insertion index 1, contrary to its comment); undefined ref starts at 0. Calls insertCore repeatedly, incrementing physical index. rearrangeToFront searches physical indexes from toIndex for first strict-equal value; if nondeleted and from!=to and to!=from+1, moveCore directly on physical indexes; break even when first equal entry was deleted. Do not replace either method with value-based Swift equality or clean live-array algorithms. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:175-197`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:257-278`.

Local toggle(entryId): find live chain tail; if isRollback===true return. Increment pending-delete on **addressed entry**, invert tail.isDeleted, build explicit isDeleted op, emit valueChanged then revertible then attached submission. toggleMove(old,new): if tail(new).isRollback true or addressed new entry isDeleted return; increment addressed old pending-move; updateLiveEntry(new,old); emit same local event/submission sequence. Revertible.revert calls toggle for insert/delete/toggle, toggleMove(entryId,changedToEntryId) for move, and reversed arguments for toggleMove; dispose is no-op. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:341-405`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArrayRevertible.ts:21-50`.

### Chain helpers (normative, not ordinary array links)

isLocalPending(id,counter): test addressed counter>0; then follow truthy prev IDs and truthy next IDs, returning true on **truthy** neighbor counter (even negative), otherwise false. updateLiveEntry(old,new): same ID→isDeleted=false only. Otherwise prepare new by reconnecting its previous.next to new.next and its next.prev to new.prev wherever IDs resolve; clear new.prev/new.next. Then old.next=new, new.prev=old, new.deleted=false, old.deleted=true. updateDeadEntry(existing,dead): if existing.next defined, dead.next=existing.next and successor.prev=dead; existing.next=dead; dead.prev=existing; dead.deleted=true. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:537-573`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:880-955`.

### Sequencing and conflict resolution

Process op envelope members in order; non-op ignored. After any recognized **remote** op emit valueChanged(originalOp,false,array), even if suppressed/no visible change. No remote revertible and no local-ACK event. Unknown type throws `Unknown operation`. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:579-628`.

- Insert local ACK clears addressed entry.isAckPending only. Remote computes physical index 0 or find(anchor)+1 (missing anchor yields 0), creates entry with ACK flag false; from that index skip consecutive isAckPending entries, then splice. Earlier sequenced same-anchor inserts thus sit after later same-anchor inserts; pending local inserts stay ahead of incoming insert until ACK. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:631-647`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:855-878`.
- Delete ACK decrements addressed pending-delete and removes ID from remote-delete Set. Remote with pending delete anywhere in chain records ID in Set, otherwise marks live tail deleted. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:650-663`.
- Move first handleInsert(new ID,anchor,local,old addressed value). ACK decrements addressed pending-move. Remote with pending delete/move anywhere in chain inserts new identity as **dead** after addressed entry; otherwise remember tail.isDeleted, updateLiveEntry(tail,new), restore deleted=true on new if old tail deleted. Locally pending moves/deletes mask earlier remote moves, later sequenced operations converge chain position without resurrecting deleted values. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:666-696`.
- Toggle ACK decrements addressed delete counter only when truthy. Remote applies explicit isDeleted to tail iff no pending-delete in chain. ToggleMove ACK decrements addressed move counter only when truthy. Remote applies updateLiveEntry(current tail,op.entryId) iff neither pending delete nor move in chain and tail.isDeleted===false; changedToEntryId isn't used on that remote branch. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:699-726`.

### Array reconnect, rollback and stash

Disconnect no-op. ReSubmit inherits original content/metadata forwarding with no local replay or new IDs. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:527`, `reference/fluidframework-3.11.0/packages/dds/shared-object-base/src/sharedObject.ts:474-476`.

Rollback ignores metadata; emits only synthetic valueChanged(op,true,array), never revertible/submission:

1. Insert: tail.deleted=true, tail.isRollback=true; emit delete with original ID.
2. Delete: if Set contains original ID, remove it **only** (does not decrement pending counter); otherwise tail.deleted=false,tail.isRollback=true, emit insert(type,entryId,value) with no anchor, then decrement addressed pending-delete if>0.
3. Move: if addressed new entry.deleted return. Mark addressed old.isRollback=true; updateLiveEntry(new,old), clear old.prev/next and pending-move=0; emit move(type,entryId:new,changedToEntryId:old), no anchor.
4. Toggle: invert tail.deleted, decrement **tail** pending-delete, mark tail.rollback=true, emit toggle(type,entryId:original,isDeleted:tail.deleted).
5. ToggleMove: decrement addressed old.pending-move, mark addressed new.rollback=true, updateLiveEntry(old,new), emit toggleMove(type,entryId:new,changedToEntryId:old).

Unknown rollback unreachable-case failure. These are not general history inversion and have deliberately asymmetric counters/flags. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:408-498`.

Stash preserves original identities, emits no public event/revertible, submits original op afterward. Insert: physical anchor+1 or 0, create ACK-pending entry, **do not skip** pending inserts. Delete: tail.deleted=true, addressed pending-delete++. Move: create ACK-pending new position with old value; if chain pending delete/move insert dead, otherwise updateLiveEntry(tail,new) preserving prior tail deletion; then addressed old.pending-move++. Toggle: assign tail.deleted=op.isDeleted, addressed pending-delete++. ToggleMove: updateLiveEntry(tail,op.entryId), addressed pending-move++ (no remote-style guard). Unknown unreachable. Shared-base handle decoding runs before stash. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:958-1033`, `reference/fluidframework-3.11.0/packages/dds/shared-object-base/src/sharedObject.ts:541-542`.

### Signal lifecycle

notify detached returns without event or submission. Attached builds op, emits notify(metadata,true), then submits. Remote op envelopes dispatch signal→notify(metadata,false); local ACK/non-op ignored without type validation. Unknown remote op throws. No persisted notification state or pending-op records. Disconnect no-op, inherited reSubmit forwards original op (remote peers may receive delayed notification). Rollback unconditional no-op: optimistic local event is not undone. Stash recognizes signal but deliberately does nothing/no event/submission; unknown stash unreachable-case failure. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/signal/sharedSignal.ts:86-100`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/signal/sharedSignal.ts:130-185`, `reference/fluidframework-3.11.0/packages/dds/shared-object-base/src/sharedObject.ts:474-476`.

## JS-semantics hazards

Physical array order includes dead positions; chain prev/next are identity-history links, not physical neighbors. Never persist just get(). Retain strict identity equality for object-valued bulk/rearrange searches. Flags/counters are mutable numbers, not booleans; truthiness differs from >0 in chain traversal. A summary clears flags in live state and may alter subsequent conflict handling; retain operation/event/reentrancy order. Undefined value summaries can throw before flag clearing, whereas undefined op fields omit. Serializer and JSON number/UTF-16 semantics apply recursively; signal rollback cannot retract an emitted event. `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:128-151`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:175-197`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/array/sharedArray.ts:537-573`, `reference/fluidframework-3.11.0/packages/dds/legacy-dds/src/signal/sharedSignal.ts:166-184`.
