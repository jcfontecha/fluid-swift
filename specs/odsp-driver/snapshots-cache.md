# ODSP snapshot retrieval, prefetch and epoch coherence

## Role

The storage manager selects cached/network snapshots, converts ODSP JSON or compact bytes to ISnapshot, and initializes tree/blob/op state. EpochTracker wraps all file REST traffic and persisted cache access so a restored/overwritten file cannot continue collaboration with stale state. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspDocumentStorageManager.ts:263-467`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/epochTracker.ts:82-102`.

## Wire and persisted formats

Let S=snapshotStorageUrl and B=a fresh UUID boundary. Trees-latest uses actual **POST** `S/trees/latest?ump=1` with defined snapshotOptions appended in JS property order, excluding timeout, then `groupId=<encodeURIComponent(ids.join(","))>` iff loadingGroupIds is defined. `undefined` omits groupId, `[]` sends `groupId=`, `["g1","g2"]` sends `groupId=g1%2Cg2`. Keys are not percent-encoded; values use encodeURIComponent (spaces `%20`, not `+`). Example `?ump=1&mds=500000000&blobs=2&groupId=`. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/fetchSnapshot.ts:762-809`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/getQueryString.ts:12-25`.

Actual Content-Type is `multipart/form-data;boundary=B`; actual `accept` is `application/ms-fluid; v=1.0` only for Binary=1; **all other values, including Json=0**, use `application/json, application/ms-fluid; v=1.0`. Body is this literal CRLF-separated sequence (no ordinary multipart Content-Disposition):

```text
--B\r\n
X-RequestStats: driverId=UUID, RequestNumber=1, driverVersion=3.11.0, isSummarizer=false\r\n
[x-fluid-epoch: E\r\n]
[X-CLP-Compliant-App: true\r\n]
Authorization: Bearer TOKEN\r\n
X-HTTP-Method-Override: GET\r\n
prefer: manualredirect\r\n
[sl: SHARING_LINK\r\n]
_post: 1\r\n
\r\n
--B--
```

Square brackets mark optional whole lines, not emitted bytes. `prefer` becomes `manualredirect, nonDurableRedeem` iff shareLinkInfo.isRedemptionNonDurable===true. EpochTracker inserts its lines immediately after boundary before Authorization; without tracker, correlation/epoch lines are absent and CLP is appended after prefer if resolved flag is defined (including false). With tracker, CLP is emitted only if truthy. Correlation counter starts 1 and optional `, fetchReason=<reason>` is appended iff reason defined. Source: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/fetchSnapshot.ts:638-671`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/fetchSnapshot.ts:788-829`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/epochTracker.ts:385-450`. The exact CLP spelling is defined by `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/contractsPublic.ts:46-56`.

JSON response schema: `{id:string,trees:[{entries:Entry[],id:string,sequenceNumber:number}],blobs?:[{content:string,encoding?:"base64",id:string,size:number}],ops?:[{op:SequencedDocumentMessage,sequenceNumber:number}]}`. Entry is `{path:string,type:"tree",unreferenced?:true,groupId?:string}` or `{id:string,path:string,type:"blob"|"commit"}`. Trees-latest requires both trees and blobs fields, even when empty; it subsequently uses trees[0], so a usable response needs a first tree. Example:

```json
{"id":"response","trees":[{"entries":[{"path":".app","type":"tree"},{"id":"b","path":".app/header","type":"blob"}],"id":"s","sequenceNumber":0}],"blobs":[{"content":"aGk=","encoding":"base64","id":"b","size":2}],"ops":[]}
```

Response JSON order is not constrained. Binary response is the full typed byte grammar in [compact snapshot](compact-snapshot.md), not JSON/base64-wrapped bytes. Content-type classification checks substring `application/ms-fluid` first, then `application/json`. Other/missing type → nonretryable incorrectServerResponse. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/contracts.ts:119-167`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/fetchSnapshot.ts:383-449`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/fetchSnapshot.ts:478-535`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/fetchSnapshot.ts:694-702`.

Specific version download uses GET `S/trees/<versionId>` (raw interpolation). Full latest adds `?deltas=1&blobs=2`; full nonlatest adds `?blobs=2`; non-full adds no query. It parses JSON, not content-negotiated binary. Versions endpoint GET `S/versions?top=N` returns `{value:[{id:string}]}`; public result adds treeId undefined. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/fetchSnapshot.ts:92-115`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspDocumentStorageManager.ts:470-552`.

Persistent snapshot key: `{type:"snapshot"|"snapshotWithLoadingGroupId",key:"",file:{resolvedUrl,docId:hashedDocumentId,fileVersion}}`; selected by `Fluid.Container.UseLoadingGroupIdForSnapshotFetch2`. Epoch envelope is `{value:SnapshotCachedEntry,fluidEpoch:string,version:3}`. SnapshotCachedEntry is `{snapshotTree,blobContents:Map<string,ArrayBuffer>,ops:SequencedMessage[],sequenceNumber?:number,latestSequenceNumber?:number,snapshotFormatV:1,cacheEntryTime:number}`; old same-envelope entries use `blobs:Map` instead of blobContents and no snapshotFormatV. Legacy entries are converted on read. Structured clone is necessary: JSON-stringifying a Map loses contents. Prefetch memory result adds `fluidEpoch,prefetchStartTime` (monotonic performance timestamp), not cacheEntryTime replacement. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspUtils.ts:499-518`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/contracts.ts:201-247`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspDocumentStorageManager.ts:305-340`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspCache.ts:155-158`.

Attachment upload POST `attachmentPOSTStorageUrl/content` sends raw bytes and `Content-Type:application/octet-stream`, optional `Prefer:Increase-Attachment-Size-Limit` when `Fluid.Driver.Odsp.enableLargeBlobUpload` truthy, receives `{id:string,...}`. Attachment download GET `attachmentGETStorageUrl/<encodeURIComponent(blobId)>/content` reads bytes; missing cache-control or one not containing private/public logs NonCacheableBlob but still returns/cache-processes bytes. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspDocumentStorageManager.ts:132-227`.

## Behavior

### Response conversion and caching

1. Set abort timer iff snapshotOptions.timeout is defined, directly in **milliseconds**; clear when downloader resolves/rejects (before consuming response body). Read text/ArrayBuffer; empty/read failure maps to 712 incorrect response. JSON.parse syntax errors and non-Fluid binary errors are wrapped as nonretryable genericError; existing Fluid errors are augmented/rethrown. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/fetchSnapshot.ts:359-535`.
2. JSON hierarchy starts `{id:trees[0].id,blobs:{},trees:{}}`, lookup[""]=root. For each flat entry, split at last slash, require previously inserted parent by lookup; tree creates child including unreferenced/groupId (even undefined), blob assigns id, **commit is ignored**. No URL decoding of path names. Decode blob encoding base64 or undefined→utf8; sequence from first tree; ops are wrapper.op; latest from last wrapper.sequenceNumber, or tree sequence; snapshotFormatV=1. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspSnapshotParser.ts:19-85`.
3. Cache eligibility: header `disablebrowsercachingofusercontent` is not exactly `"true"` AND no nonempty loadingGroupIds. Validate `sequenceNumber ?? 0` is integer, and if ops nonempty first op.sequenceNumber−1 equals that value. Failure logs fetchSnapshotError, sets snapshot.sequenceNumber undefined and does not cache. Eligible valid response requires epoch header (0x1e6); add cacheEntryTime Date.now and envelope version 3, then invoke cache put **without awaiting**. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/fetchSnapshot.ts:538-575`.
4. Final snapshot fetch failure `fetchFailure` or `fetchTimeout` gets repeat marker for the one token-refresh retry. After manager network path fails, force error.canRetry=false to prevent outer storage retries switching to stale individual-download paths. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/fetchSnapshot.ts:615-629`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspDocumentStorageManager.ts:555-577`.

### Snapshot selection transitions

State starts `firstSnapshotFetchCall=true`, source unknown. `fetchSource=noCache` → network with avoid-prefetch true. Otherwise start persisted read; summarizer rejects cache age **>60000ms**; first non-summarizer call with concurrentSnapshotFetch truthy also starts network. Race waits first completion with both errors temporarily converted to undefined; if winner empty, await other source; if both empty/fail, surface original network failure. Losing network is not cancelled and can update cache. All other calls are serial cache→network on miss. A successful winner initializes state in order: snapshot sequence, commit cache if requested, blob cache always, ops only for initial fetch, event SnapshotInitializeTime, set first flag false. `_isFirstSnapshotFromNetwork` is false only for method cache (prefetch is treated network). Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspDocumentStorageManager.ts:263-467`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspDocumentStorageServiceBase.ts:282-308`.

Network first attempts consume one prefetched promise if present unless noCache, host avoidPrefetchSnapshotCache, or not first call. Remove it before validating epoch; failure logs PrefetchSnapshotError and proceeds normal fetch. Default effective options `{mds:500000000,...hostOptions,timeout: hostTimeout ? min(hostTimeout,120000) :120000}`; summarizer sets mds/timeout undefined. Explicit host mds on snapshotTooBig fails immediately (except summarizer). Otherwise snapshotTooBig/fetchTimeout with truthy original blobs → retry with `{...options,blobs:0,mds:undefined,timeout:undefined}`. No blobs truthy means no such fallback. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspDocumentStorageManager.ts:580-726`.

getVersions(nonempty blobid other than docID) returns singleton directly, no request. Missing snapshotURL→[]. count=1 and (blobid null or docID)→trees-latest path; otherwise versions endpoint. Public getSnapshotTree combines `.app` contents at root, attaches service `.protocol` overriding app's same key; root id preserved. downloadSummary throws `Not implemented yet` in this oracle. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspDocumentStorageManager.ts:470-552`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspDocumentStorageServiceBase.ts:230-279`.

### Prefetch transitions

Start → choose [] groups iff group feature truthy; create token wrapper and snapshot cache key; add Deferred promise under same nonpersistent key before network; fetch with redeem. put callback captures epoch and persistent-put promise. Success → assert epoch truthy (0x585), resolve Deferred with snapshot+epoch+prefetchStartTime, require put occurred (0x1e7), await put, schedule memory removal after **5000ms**, return true. Failure → remove promise, reject Deferred, log PrefetchLatestSnapshotError, return false. Deprecated binary-format arguments and force-header argument are ignored. Prefetch has **no EpochTracker**; fetched envelope itself supplies persisted epoch. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/prefetchLatestSnapshot.ts:68-191`.

### Epoch transitions and invalidation

- **Unknown→Known(E)**: first cache response with envelope version 3/defined epoch, or network defined epoch, sets epoch once and emits EpochLearnedFirstTime (fields epoch/fetchType/fromCache). Re-setting asserts 0x1db. Cache can teach epoch even before its age rejection. Missing network epoch is permitted in ordinary fetch, but explicit validateEpoch (including socket/prefetch) requires defined epoch 0x584. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/epochTracker.ts:133-194`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/epochTracker.ts:234-241`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/epochTracker.ts:453-465`.
- **Known(E)+cache(E)**: snapshot requires cacheEntryTime and age **<432000000ms** (or <0 for disable-cache override); stale/missing time logs odspVersionsCacheExpired, removes all file entries, returns undefined. Version mismatch→undefined; cache epoch mismatch→undefined without delete/error. Read exceptions log cacheFetchError→undefined. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/epochTracker.ts:119-194`; five-day constant `reference/fluidframework-3.11.0/packages/loader/driver-utils/src/cacheUtils.ts:16`.
- **Known(E)+network(F)** with both E/F truthy and E≠F → nonretryable fileOverwrittenInStorage, message Epoch mismatch, serverEpoch/clientEpoch. checkForEpochError removes all file entries, emits fileOverwrittenInStorage and throws mismatch. **409 with same/missing epoch** → replace by ThrottlingError(`Coherency 409: ...`,1 second), property Odsp409Error=true. Epoch is never updated to F. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/epochTracker.ts:467-515`.
- Each put requires known epoch (0x1dd), fills snapshot cacheEntryTime only if nullish, wraps `{value,version:3,fluidEpoch:E}`, propagates put failure after cachePutError. removeEntries errors log and are swallowed. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/epochTracker.ts:199-228`.
- Request path: increment correlation→insert epoch/correlation/CLP→merge immutable host headers→queue in **24-concurrent** limiter→fetch→capture response epoch→validate→attach correlation telemetry. Error path captures error.serverEpoch if needed→epoch conversion→on fileNotFoundOrAccessDeniedError with redirectLocation, patch resolved URL and clear file cache then throw LocationRedirectionError→normalize with correlation. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/epochTracker.ts:119-130`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/epochTracker.ts:294-357`.

EpochTrackerWithRedemption has a separate pending access Deferred. Any successful network validation or nonempty snapshot cache read resolves it; treesLatest JSON fetch failure rejects it. joinSession failure with status **401 through 404 inclusive**, and Deferred incomplete **at request start**, waits for Deferred or **15000ms** then retries once; Deferred rejection propagates; timeout cancels JoinSessionSyncWait event then proceeds. If it was already completed at start, never wait/retry. This is redemption synchronization, not an unbounded auth retry. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/epochTracker.ts:523-646`.

Share-link fallback: legacy root sharingLinkToRedeem is migrated to shareLinkInfo. When a share link is defined and the error is authorizationError or fileNotFoundOrAccessDeniedError, with enableRedeemFallback truthy, redeem GET `<site origin>/_api/v2.0/shares/u!<base64url(UTF8(encodeURI(link)))>/driveItem`, header prefer redeemSharingLink or nonDurableRedeem, then repeat latest without sharingLinkToRedeem. `u!` encoding strips `=`, maps `/`→`_`, `+`→`-`. Final authorization/file-not-found failure clears cache before throw. Redirect with share link attempts redeem on redirected location and still rethrows redirect, logging redeem failure if any. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/fetchSnapshot.ts:137-309`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/fetchSnapshot.ts:840-873`.

Public getSnapshot forces fetchSource=noCache for nonempty loadingGroupIds, and normalizes undefined loadingGroupIds to []; it returns a copy with combined app/protocol tree. getSnapshotTree has missing-snapshotURL→null and inherited commit lookup; fetching uncached specific tree requires root id (0x222), caches root/blobs, returns commitCache.get(requestedId) ?? commitCache.get(returnedRootId). Initial ops setter can be assigned only once (0x0a5). Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspDocumentStorageManager.ts:230-260`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspDocumentStorageManager.ts:874-915`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspDocumentStorageServiceBase.ts:154-159`.

LocalPersistentCache is not disk persistence: Map key is shared driver cache key; default sliding expiration **3600000ms per docId**, reset only on put (not get). removeEntries cancels document timer and removes keys whose first underscore-delimited component equals docId. PromiseCacheWithOneHourSlidingExpiry uses3600000ms sliding; the actual NonPersistentCache session/file/prefetch caches are default PromiseCache instances, not that subclass. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspCache.ts:39-148`.

## JS-semantics hazards

Do not conflate absent/empty/nonempty group IDs. Cache operations preserve Map/binary data rather than JSON encoding. Timers use milliseconds despite ISnapshotOptions documentation saying seconds. Date.now controls expiry; performanceNow controls telemetry. Cache and network race has observable epoch-learning order; actor serialization must not replace it with an unordered parallel map. Blob cache bulk-init keeps all sizes; subsequent individual fetch caches only size **<262144** bytes. Initial eviction timer 120000ms, subsequent 10000ms; access while timer pending sets a defer flag rather than resetting timer. Sources: `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspDocumentStorageManager.ts:344-420`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/fetchSnapshot.ts:361-364`, `reference/fluidframework-3.11.0/packages/drivers/odsp-driver/src/odspDocumentStorageServiceBase.ts:25-122`.
