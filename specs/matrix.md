# matrix — client 3.11.0

## 1. Role

SharedMatrix is a sparse, rectangular, collaborative value grid. Two independent merge-tree Clients order rows and columns; **local storage handles are not replicated coordinates**. Cell ops address the sender's logical row/column at its reference sequence. Values use Fluid serialization (JSON plus handles). `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:240-278`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/permutationvector.ts:129-154`.

## 2. Surface used by other packages

## 3. Wire and persisted formats

### Operations

Dispatch is by `target` **before type**. The MatrixOp enum is spliceCols=0, spliceRows=1, set=2, but current vector edits are merge-tree ops with target, not spliceCols/spliceRows payloads. Current cell writer emits, in insertion order:

```json
{"type":2,"row":0,"col":1,"value":"x","fwwMode":false}
```

`row`/`col` are numeric logical coordinates; value is any MatrixItem. Clearing emits `{"type":2,"row":0,"col":1,"fwwMode":false}` because undefined `value` is omitted, and reading absent value yields undefined. `target` must be absent for set. Reader accepts omitted `fwwMode` (historical LWW); only literal true initiates FWW. Example after switch: `{"type":2,"row":0,"col":1,"value":7,"fwwMode":true}`. No localSeq, handles, refs, or original reference sequence is in this payload. Those belong to local metadata. `reference/fluidframework-3.11.0/packages/dds/matrix/src/ops.ts:14-47`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:485-523`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:1042-1068`.

Vector writer spreads merge-tree op then appends target `"rows"` or `"cols"`. All merge-tree op fields/types and GROUP semantics are specified in [merge-tree operations](merge-tree/operations.md). Matrix's normal public structural paths generate INSERT/REMOVE (regeneration can emit GROUP). Examples:

```json
{"pos1":0,"seg":[3,-2147483648],"type":0,"target":"rows"}
{"pos1":1,"pos2":3,"type":1,"target":"cols"}
{"ops":[],"type":3,"target":"rows"}
```

PermutationSegment JSON is exactly `[cachedLength,startHandle]`, both numbers; unallocated=-2147483648, none=0, valid handles>=1. **On op insertion the incoming start is reset to unallocated**, even when the sender inserted a segment whose JSON contained allocated handles. On snapshot load start handles are retained. `reference/fluidframework-3.11.0/packages/dds/matrix/src/permutationvector.ts:46-86`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/permutationvector.ts:367-383`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:551-583`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/handletable.ts:6-24`.

### Summary tree, versions and exact arrays

Writer adds **rows subtree, cols subtree, cells blob**, in that order. Each vector subtree adds **segments subtree, handleTable blob**, in that order. `segments/header` and optional `segments/body_N` are merge-tree V1 chunks; vectors force `newMergeTreeSnapshotFormat:true` over runtime options. The inherited reader still accepts legacy unversioned and string-`"1"` chunks and merge metadata compatibility defined in [snapshots](merge-tree/snapshots.md). Vector load loads handleTable first, then delegates segments load; it does not introduce another version discriminator. `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:695-743`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/permutationvector.ts:146-154`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/permutationvector.ts:308-345`.

`handleTable` blob is the numeric array itself. Slot 0 is free-list head, allocated slots are 0, free slots are next-free links, and the terminal free index may equal array length. Initial `[1]`; allocate handles 1,2 produces `[3,0,0]`; freeing 1 produces `[1,3,0]`; next allocate reuses 1 and restores `[3,0,0]`. Load uses array as provided, without normalization. `reference/fluidframework-3.11.0/packages/dds/matrix/src/handletable.ts:29-61`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/handletable.ts:78-111`.

`cells` is Fluid-serializer stringification of positional array:

```
[cellsRoot, [undefined], -1]                       // off OR local switch not sequenced
[cellsRoot, [undefined], switchOpSeqNumber, trackerRoot] // on
```

Undefined inside arrays serializes to null. Thus a new empty LWW matrix has cells blob `[[null],[null],-1]`; empty FWW switched while detached has `[[null],[null],0,[null]]`. The historical pending slot (index 1) is always `[null]` now and **ignored on read**, even if populated in old summaries. Readers accept missing/null switch index as off, -1 as off, and any other present number as on, loading index 3 as tracker. No separate schema version gates these trailing fields. A local unsequenced policy request is deliberately not persisted as on. `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:706-741`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:947-975`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:1214-1222`.

Sparse roots are **nested arrays, not lists of occupied triples**. Define Morton16(r,c) by interleaving the low 16 bits, column bits in even positions and row bits in odd positions, coerced UInt32. Set `hi=Morton16(row>>>16,col>>>16)`, `lo=Morton16(row,col)`; path is `root[hi][lo>>>24][(lo>>>16)&255][(lo>>>8)&255][lo&255]`. Initial root `[undefined]`; each missing child created on write is a length-256 array filled with undefined. Root extends only as needed; intermediate/leaf arrays stay length 256. The cell at storage handles (1,1) has lo=3, so writing 7 makes root length 1, its path children at 0,0,0 have length 256, and leaf index 3=7 (all other entries null in JSON). Exact expanded example is defined by `A(v)=[v,null repeated 255 times]`, `B=[null,null,null,7,null repeated 252 times]`: the root is `[A(A(A(B)))]`. This is one root plus four nested 256-length arrays, not a compact five-number tuple. Tracker leaf values are objects in order `{seqNum:number,clientId:string}`, e.g. `{ "seqNum":12,"clientId":"alice" }`, at the identical handle path. `reference/fluidframework-3.11.0/packages/dds/matrix/src/sparsearray2d.ts:15-43`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/sparsearray2d.ts:65-104`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/sparsearray2d.ts:237-250`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:1093-1096`.

Sparse load recursively maps null to undefined **through every array**, including arrays used as cell values; it leaves object members intact. Consequently nested nulls in array cell values do not round-trip as null through this loader, even though MatrixItem's type permits them. Clearing writes undefined slots without shrinking arrays or pruning children. Preserve these shapes for byte-exact summaries. `reference/fluidframework-3.11.0/packages/dds/matrix/src/sparsearray2d.ts:48-55`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/sparsearray2d.ts:182-250`.

## 4. Behavior

### Storage and structural mutations

Rows/cols begin empty. An inserted length-n span uses one unallocated PermutationSegment; cells do not move when logical rows/cols move. Reading gets row handle, then col handle, then sparse cell; invalid row handle still bounds-checks col and returns undefined. Allocating a logical position splits `[pos,pos+1)` into a one-item segment, assigns a free handle and updates cache; it is local storage work, not a replicated insert. A split right start is unallocated if left was unallocated, otherwise start+splitOffset. Clone uses start+cloneOffset literally, including for negative sentinel. Append permitted when both starts unallocated or other's start==start+length. `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:371-389`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/permutationvector.ts:89-119`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/permutationvector.ts:160-198`.

Structural APIs return immediately when count===0, **before bounds/reentrancy checks**. Start>current count throws API-specific UsageError; other range validation belongs to merge-tree local insert/remove. Insert applies local segment mutation, then submits; remove applies local range `[start,start+count)`, then submits. All nonzero public structural edits run under the reentrancy guard. Before vector submit synchronize opposite localSeq to submitting vector localSeq (must be >= opposite). Attached submission targets rows/cols, captures pending segment groups (GROUP member count or 1), and enqueues refSeq; detached structural state only enters the eventual attach summary. `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:551-645`.

For each merge-tree vector delta, build segment/current-position pairs and sort **ascending** by position (`left.position-right.position`), despite the source comment claiming descending. Record local undo first. For INSERT, reset every segment start unless rollback; invalidate every affected cache range; then send every structural callback `(position,0,length)`. For REMOVE invalidate every range first, then callbacks `(position,length,0)`. Other delta types throw `Unhandled MergeTreeDeltaType`. Matrix fans these out to consumers in Set insertion order as rowsChanged/colsChanged with matrix as final argument. Structural callbacks occur inside merge-tree delta handling, **before** the public API submits its vector op. `reference/fluidframework-3.11.0/packages/dds/matrix/src/permutationvector.ts:348-418`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:1166-1186`.

HandleCache stores consecutive handles and uses UInt32(position-start) as index. On a miss extend to requested position, bounds-checking via UInt32; each handle is segment.start+offset. itemsChanged truncates from start's cached index when in range, ignoring removed/inserted counts. An unallocated negative start plus offset stays invalid until allocated. On UNLINK only, enumerate all allocated handles in removed spans; **first clear cells, pending and FWW tracker rows/cols**, then push handles into free list in enumeration order. Logical removal alone must not recycle. Tracking groups used by undo delay UNLINK and therefore preserve cells. `reference/fluidframework-3.11.0/packages/dds/matrix/src/handlecache.ts:31-137`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/permutationvector.ts:421-445`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:1188-1211`.

### Local sets, pending state and ordering

setCell rejects row<0,row>=rowCount,col<0,col>=colCount with UsageError. setCells computes ceil(values.length/colCount) and asserts 0<=starts<dimensions, 1<=colCount<=remaining columns and sufficient remaining rows; iterates values row-major, wrapping to original colStart, invoking setCellCore once per value (not one bulk op). Even an empty values array still validates starts/width. `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:398-437`.

setCellCore evaluates default allocated row/col handles **before** entering reentrancy protection. Then: oldValue=cells.getCell(...)??undefined; record undo; store value; if attached and not rollback send set op; if this is first pending entry initialize consensus with oldValue via ??=; notify each consumer cellsChanged(row,col,1,1,self). sendSetCellOp defaults localSeq to ++both vector windows (cols first then rows), creates StayOnRemove references at `(pos,localSeq)`, local metadata in order `{rowHandle,colHandle,localSeq,rowsRef,colsRef,referenceSeqNumber:lastSequenceNumber}`, submits, then appends `{localSeq,value}` to per-cell pending.local. Thus op queue precedes notifications. `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:439-523`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:764-789`.

Reentrancy guard throws `Reentrancy detected in SharedMatrix.` if count!=0, increments, runs callback, decrements in finally, asserts 0x85e. Local edit consumer callbacks therefore cannot submit nonzero structural edits or sets; no asynchronous dispatch substitute. Remote apply itself is not wrapped by that local guard. `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:534-548`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:1018-1164`.

### Resolution state machine and receive

Policy starts **off**. switchSetCellPolicy changes off→local if attached, off→on(seq=0,empty tracker) if detached, otherwise no-op. API query returns true for local or on. local sends fwwMode=true but still resolves receives as LWW until processing the first true op. On any set with fwwMode===true and policy!=on, change to on with switchOpSeqNumber=message.sequenceNumber and fresh empty tracker **before local/remote branch**. There is no on→off transition. switchOpSeqNumber is persisted, not used as an additional per-op acceptance comparison. `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:215-222`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:367-369`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:1060-1068`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:1214-1223`.

Process collection members sequentially, reconstructing envelope with member contents/clientSequenceNumber. Local message shifts inFlightRefSeqs and asserts present. Dispatch rows/cols to only the target Client.applyMsg (other vector does not receive dummy op); target absent requires type=2; any other target is unreachable error. A set requires nonnull sender. `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:1011-1070`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:1160-1162`.

FWW acceptance predicate for handles h is: tracker absent OR tracker.clientId==sender OR message.referenceSequenceNumber>=tracker.seqNum. This permits same-client successive writes without needing to observe their own earlier acknowledgement; it is not unconditional first-ever-write-wins. `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:988-1008`.

Local set ack: remove metadata refs; shift first pending.local entry (must match localSeq); remove sparse pending cell if list now empty; if on and accepted, assign acked value to the retained pending object.consensus and set tracker to `{seqNum:seq,clientId:sender}`. No cells write, consumer notification or conflict event is emitted in the ack branch, **including a rejected FWW ack**. Off-mode ack does not update consensus here. `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:1071-1097`.

Remote set: resolve sender's logical positions via each vector.getContainingSegment(position,{referenceSequenceNumber,clientId}). If segment currently removed, allocate a handle if needed by splitting the sender-perspective unit and return `{handle,pos:undefined}` (no cache entry); if live return local position+allocated handle. Both handles must be valid. Still apply writes to retained removed rows/cols so a local removal rollback can recover them, but notify only if **both** adjusted positions exist. The removed branch returns segment.start literally when already allocated; it does not add offset there. `reference/fluidframework-3.11.0/packages/dds/matrix/src/permutationvector.ts:200-245`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:1098-1108`.

- Off/local (LWW): if pending absent or local list empty, store remote value then notify when both positions live. Otherwise update only pending.consensus, leaving optimistic value visible.
- On (FWW): if predicate fails, no effects. If accepted, save previous visible value; store remote value; set tracker; update pending.consensus if present; notify live cell; then, if pending.local nonempty, emit `conflict(row,col,value,previousValue,self)`. **Conflict uses original wire row/col**, unlike consumer notification's adjusted coordinates. Pending entries are retained, so another accepted op can raise another conflict. No conflict when either axis removed.

`reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:1110-1155`.

### Reconnect, stashing, rollback, undo, loading

didAttach starts both collaborations with runtime clientId or `attached`; onConnect asserts both collaboration flags equal and updates both client identities. Each submit stores lastSequenceNumber in one shared FIFO (a lower bound for the eventual envelope refSeq) and asserts row/col localSeq equal. Disconnect is no-op. `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:264-273`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:774-810`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:933`.

Resubmit first shifts originalRefSeq and asserts present; the variable is **not otherwise used**. Cell rebase rejects missing ref segment/offset or **any currently removed** segment; else returns findReconnectionPosition(segment,original localSeq)+offset. Remove old refs; find/splice matching pending entry (assert exists). Resend with same localSeq and current policy only if both rebased positions defined/nonnegative AND (not on OR original metadata.referenceSeqNumber>=tracker.seqNum default 0). New metadata captures current lastSequenceNumber and new refs, and pending entry re-appends. A suppressed resend does **not** emit a conflict, restore cells, or delete empty pendingCell here, despite nearby comments suggesting a conflict. Vector resubmit uses regeneratePendingOp(...,false), re-targets and submits even empty GROUP. `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:812-889`.

Stashed set optionally switches policy then calls setCell (fresh refs/localSeq/pending); stashed vector applies to selected vector then submits target; non-cols fallback selects rows. Rollback dispatches vector Client.rollback by target; cell rollback pops matching pending tail, chooses last remaining local.value else consensus, invokes setCellCore with saved handles and rollback=true, notifying and recording undo but not submitting. This branch does not delete pending entry, remove metadata refs, or shift inFlightRefSeqs. `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:892-931`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:1246-1261`.

openUndo accepts exactly one consumer. Local vector deltas record merge-tree revertibles; removal additionally tracks each segment to prevent reclamation. Before undo reinsertion, unlink removal tracking and reset old segment's handles; reinsertion restores original handles to new segment and invalidates cache after structural callback. Submit vector op, then resend populated cells (skip null/undefined) in row-major order for restored rows, column-major for restored columns; emit cellsChanged rectangle afterward. Cell undo captures handles/old value, maps handles back through retained segments+reconnection positions, and calls setCell if row<rowCount and col<colCount. Undo is new replicated work, not rollback. Discard releases tracking/revertibles. `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:327-333`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:647-692`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/undoprovider.ts:38-90`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/undoprovider.ts:101-137`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/undoprovider.ts:178-195`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/permutationvector.ts:462-489`.

Load rows then cols then cells/tracker, each awaited; any error logs `MatrixLoadFailed` and is **swallowed**, not rethrown (potential partial state). Summarization includes current sparse storage, not logical-row iteration; GC separately iterates logical row-major and serializes every getCell to collect handle routes. `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:695-755`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:935-981`.

## 6. JS-semantics hazards

Matrix axes count **items, not UTF-16**; a string-valued cell is indivisible. Cell strings and client IDs still require JSString preservation of surrogate pairs and lone surrogates through Fluid serialization. Inherited merge-tree **ordinals compare UTF-16 code-unit strings**, not Swift locale/grapheme order. No matrix axis operation uses JS substring/slice on text. `reference/fluidframework-3.11.0/packages/dds/matrix/src/permutationvector.ts:59-63`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:498-504`, `reference/fluidframework-3.11.0/packages/dds/merge-tree/src/ordinal.ts:9-23`.

Reproduce JS ToUint32/ToInt32 for Morton shifts and ensureRange/cache indices, not unbounded Swift integer arithmetic. API comparisons do not uniformly enforce integers/finite values; don't claim a stricter validator is TS-compatible. Preserve sparse-array lengths/holes, JSON array nulls versus omitted object `value`, nullish old-value normalization, recursive array null conversion, ascending stable sort, Set iteration/reentrancy timing, and local object identity. FWW tracker is keyed by local handles and must be cleared before handle reuse. `reference/fluidframework-3.11.0/packages/dds/matrix/src/range.ts:9-15`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/sparsearray2d.ts:15-55`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/matrix.ts:398-467`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/permutationvector.ts:348-358`, `reference/fluidframework-3.11.0/packages/dds/matrix/src/permutationvector.ts:438-445`.
